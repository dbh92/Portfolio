Thiết lập môi trường Python cho AI và Computer Vision

venv, uv, cài PyTorch nhận GPU đúng cách, cấu hình VS Code và checklist để code chạy được trên mọi máy.

Rất nhiều người bỏ cuộc khi học AI không phải vì thuật toán khó, mà vì môi trường cài đặt rối tung: xung đột phiên bản, PyTorch không nhận GPU, code chạy máy này không chạy máy kia. Bài này hướng dẫn thiết lập môi trường Python gọn gàng, có thể tái lập, cho học AI và Computer Vision.

Nguyên tắc vàng: mỗi dự án một môi trường ảo

Không bao giờ pip install thẳng vào Python của hệ thống. Mỗi dự án có một môi trường ảo riêng với phiên bản thư viện riêng.

Cách 1: venv có sẵn trong Python

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install --upgrade pip
pip install numpy opencv-python matplotlib jupyter
pip freeze > requirements.txt          # lưu danh sách phiên bản

Cách 2: uv, nhanh hơn nhiều

uv là công cụ quản lý gói và môi trường cho Python, cài thư viện nhanh hơn pip đáng kể và quản lý luôn cả phiên bản Python.

uv init vision-demo
cd vision-demo
uv add numpy opencv-python ultralytics    # tự tạo .venv và ghi vào pyproject.toml
uv run python main.py                     # chạy trong môi trường của dự án

File pyproject.toml và uv.lock giúp người khác (hoặc máy công nghiệp) tạo lại đúng môi trường chỉ bằng uv sync.

Cài PyTorch có GPU đúng cách

  1. Cài driver NVIDIA mới. Kiểm tra bằng lệnh nvidia-smi.
  2. Vào trang pytorch.org/get-started, chọn hệ điều hành, pip và phiên bản CUDA, copy đúng lệnh cài trang đó đưa ra (thường có tham số --index-url trỏ tới bản build CUDA).
  3. Kiểm tra:
import torch
print(torch.__version__)
print(torch.cuda.is_available())          # phải là True
print(torch.cuda.get_device_name(0))

Lỗi phổ biến nhất: cài ultralytics hoặc thư viện khác trước, pip kéo về bản PyTorch chỉ chạy CPU. Hãy cài PyTorch bản GPU trước, rồi mới cài các thư viện còn lại. Bạn không cần cài CUDA Toolkit riêng để chạy PyTorch; bản build của PyTorch đã kèm thư viện CUDA cần thiết, chỉ cần driver đủ mới.

Trình soạn thảo: VS Code

  • Cài extension Python và Jupyter của Microsoft.
  • Ctrl+Shift+P → Python: Select Interpreter → chọn .venv của dự án.
  • Dùng file .ipynb để thử nghiệm, xem ảnh trung gian; chuyển code ổn định sang file .py.
  • Bật định dạng tự động (ví dụ Ruff hoặc Black) để code luôn gọn.

Cấu trúc thư mục gợi ý

vision-demo/
  data/            # ảnh, dataset (không commit file lớn lên Git)
  notebooks/       # thử nghiệm
  src/             # mã nguồn chính
  models/          # trọng số đã huấn luyện
  pyproject.toml   # hoặc requirements.txt
  .gitignore       # bỏ qua .venv/, data/, models/*.pt

Checklist khi mang code sang máy khác

  • Có file khai báo phiên bản (requirements.txt hoặc uv.lock).
  • Ghi rõ phiên bản Python, driver GPU trong README.
  • Không dùng đường dẫn tuyệt đối kiểu C:\Users\ten-ban\... trong code.
  • Thử cài lại từ đầu trên một máy sạch (hoặc máy ảo) trước khi giao cho khách hàng.

Môi trường đã sẵn sàng? Bắt đầu với bài NumPy cho xử lý ảnh.
