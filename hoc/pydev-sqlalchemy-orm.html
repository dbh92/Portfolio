SQLAlchemy 2.0 ORM: model, Session, select và quan hệ

Làm việc với CSDL bằng đối tượng: SQLAlchemy 2.0 với Mapped, mapped_column, Session, select(), quan hệ một nhiều và lazy loading.

Viết SQL bằng chuỗi trong Python hoạt động tốt, nhưng khi ứng dụng lớn lên, bạn phải tự chuyển từng dòng kết quả thành đối tượng, tự ghép câu lệnh theo điều kiện lọc, và gõ sai tên cột thì chỉ biết khi chạy. ORM (Object-Relational Mapping) cho phép làm việc với bảng như với class Python. SQLAlchemy là ORM phổ biến nhất của Python, và là nền tảng CSDL cho FastAPI ở chặng 9.

1. Khai báo model

Cài: uv add sqlalchemy. Bài dùng cú pháp của SQLAlchemy 2.x (bản 2.0 trở lên), có type hint đầy đủ.

from sqlalchemy import ForeignKey, String, create_engine
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column, relationship


class Base(DeclarativeBase):
    pass


class TacGia(Base):
    __tablename__ = "tac_gia"

    id: Mapped[int] = mapped_column(primary_key=True)
    ten: Mapped[str] = mapped_column(String(100), unique=True)
    sach: Mapped[list["Sach"]] = relationship(back_populates="tac_gia", cascade="all, delete-orphan")

    def __repr__(self) -> str:
        return f"TacGia({self.ten!r})"


class Sach(Base):
    __tablename__ = "sach"

    id: Mapped[int] = mapped_column(primary_key=True)
    ten: Mapped[str] = mapped_column(String(200))
    nam: Mapped[int]
    gia: Mapped[int | None]                                   # cho phép NULL
    tac_gia_id: Mapped[int] = mapped_column(ForeignKey("tac_gia.id"))
    tac_gia: Mapped[TacGia] = relationship(back_populates="sach")

    def __repr__(self) -> str:
        return f"Sach({self.ten!r}, {self.nam})"


engine = create_engine("sqlite:///thu_vien.db")
Base.metadata.drop_all(engine)
Base.metadata.create_all(engine)          # tạo mọi bảng chưa có
print(list(Base.metadata.tables))
['tac_gia', 'sach']
  • Mỗi class kế thừa Base là một bảng; __tablename__ là tên bảng.
  • Mapped[int] khai báo cột và kiểu; Mapped[int | None] nghĩa là cột cho phép NULL, không có None thì là NOT NULL. mapped_column(...) thêm chi tiết: khóa chính, độ dài, khóa ngoại, unique.
  • relationship không phải cột: nó cho phép đi từ đối tượng này sang đối tượng liên quan (sach.tac_gia, tac_gia.sach). back_populates nối hai chiều với nhau.
  • create_engine("sqlite:///thu_vien.db"): đổi sang PostgreSQL chỉ cần đổi chuỗi kết nối, ví dụ "postgresql+psycopg://user:mk@host/db" (cần cài driver).

2. Thêm dữ liệu với Session

# (minh họa) nối tiếp mục 1
with Session(engine) as session:
    to_hoai = TacGia(ten="Tô Hoài")
    nam_cao = TacGia(ten="Nam Cao", sach=[Sach(ten="Chí Phèo", nam=1941, gia=65_000),
                                         Sach(ten="Lão Hạc", nam=1943, gia=None)])
    to_hoai.sach.append(Sach(ten="Dế Mèn phiêu lưu ký", nam=1941, gia=85_000))
    session.add_all([to_hoai, nam_cao])
    session.add(Sach(ten="Vợ chồng A Phủ", nam=1952, gia=55_000, tac_gia=to_hoai))
    session.commit()
    print(to_hoai.id, nam_cao.id, [s.ten for s in to_hoai.sach])
1 2 ['Dế Mèn phiêu lưu ký', 'Vợ chồng A Phủ']

Session là "phiên làm việc" với CSDL: bạn thêm, sửa đối tượng Python, Session theo dõi thay đổi và khi commit() thì gửi đúng các câu INSERT/UPDATE cần thiết trong một transaction. Không cần ghi tac_gia_id bằng tay: gán quan hệ tac_gia=to_hoai hoặc thêm vào list sach là đủ. Sau commit, id do CSDL sinh ra đã có trên đối tượng.

3. Truy vấn với select()

# (minh họa) nối tiếp mục 1, 2
from sqlalchemy import func, select

with Session(engine) as session:
    sach_1941 = session.scalars(select(Sach).where(Sach.nam == 1941).order_by(Sach.ten)).all()
    print(sach_1941)

    mot = session.scalars(select(Sach).where(Sach.ten.ilike("%hạc%"))).first()
    print(mot, mot.tac_gia.ten)                      # đi theo quan hệ sang tác giả

    print(session.get(TacGia, 2))                    # lấy theo khóa chính

    re_nhat = session.scalars(select(Sach).where(Sach.gia.is_not(None)).order_by(Sach.gia).limit(1)).one()
    print(re_nhat, re_nhat.gia)

    thong_ke = session.execute(
        select(TacGia.ten, func.count(Sach.id), func.min(Sach.nam))
        .join(TacGia.sach)
        .group_by(TacGia.id)
        .order_by(TacGia.ten)
    ).all()
    for ten, so_sach, nam_dau in thong_ke:
        print(f"{ten}: {so_sach} cuốn, từ năm {nam_dau}")
[Sach('Chí Phèo', 1941), Sach('Dế Mèn phiêu lưu ký', 1941)]
Sach('Lão Hạc', 1943) Nam Cao
TacGia('Nam Cao')
Sach('Vợ chồng A Phủ', 1952) 55000
Nam Cao: 2 cuốn, từ năm 1941
Tô Hoài: 2 cuốn, từ năm 1941
  • select(Sach) tạo câu truy vấn; nối thêm .where(), .order_by(), .limit(), .join(), .group_by(). Điều kiện viết bằng toán tử Python trên thuộc tính lớp: Sach.nam == 1941, Sach.gia > 50_000, Sach.ten.ilike("%hạc%"), Sach.gia.is_not(None).
  • session.scalars(...) khi chọn một thứ (đối tượng); .all(), .first() (hoặc None), .one() (đúng một, không thì lỗi). session.execute(...) khi chọn nhiều cột, kết quả là các dòng tuple.
  • Gõ sai Sach.nma là AttributeError ngay và VS Code gạch đỏ trước khi chạy: ưu điểm lớn so với chuỗi SQL.

Muốn xem SQL thật SQLAlchemy sinh ra, tạo engine với echo=True, hoặc print(select(Sach).where(Sach.nam == 1941)).

4. Sửa và xóa

# (minh họa) nối tiếp các mục trên
with Session(engine) as session:
    lao_hac = session.scalars(select(Sach).where(Sach.ten == "Lão Hạc")).one()
    lao_hac.gia = 60_000                            # sửa thuộc tính như đối tượng thường
    to_hoai = session.scalars(select(TacGia).where(TacGia.ten == "Tô Hoài")).one()
    session.delete(to_hoai)                         # cascade: xóa luôn sách của Tô Hoài
    session.commit()
    print(session.scalar(select(func.count()).select_from(Sach)), lao_hac.gia)
2 60000

Session tự phát hiện thuộc tính bị đổi và sinh UPDATE khi commit. cascade="all, delete-orphan" khai báo ở TacGia.sach làm xóa tác giả kéo theo xóa sách của họ. Thiếu cascade, xóa tác giả còn sách sẽ bị khóa ngoại chặn (với CSDL có kiểm tra khóa ngoại).

5. Lazy loading và bẫy N+1

# (minh họa) nối tiếp các mục trên
from sqlalchemy.orm import selectinload

with Session(engine) as session:
    # Mỗi lần chạm tac_gia.sach là MỘT câu SELECT mới: 100 tác giả = 101 câu truy vấn
    for tg in session.scalars(select(TacGia)):
        print(tg.ten, len(tg.sach))

    # selectinload: nạp sách của mọi tác giả trong 1 câu truy vấn thêm
    for tg in session.scalars(select(TacGia).options(selectinload(TacGia.sach))):
        print(tg.ten, [s.ten for s in tg.sach])

Mặc định quan hệ được nạp lười (lazy): chỉ khi bạn truy cập tg.sach mới truy vấn. Trong vòng lặp, điều đó sinh ra N câu truy vấn thêm, gọi là bài toán N+1, nguyên nhân số một khiến trang web chậm. Biết trước sẽ dùng quan hệ thì nạp sẵn bằng selectinload.

Thay đổi cấu trúc bảng khi đã có dữ liệucreate_all chỉ tạo bảng chưa có, không thêm cột vào bảng cũ. Dự án thật dùng Alembic (cùng tác giả SQLAlchemy) để tạo các file "migration" ghi lại từng thay đổi cấu trúc và áp dụng lên CSDL thật một cách an toàn. Bạn nên tìm hiểu Alembic sau khi xong lộ trình.

Tóm tắt

  • Model: lớp kế thừa DeclarativeBase, Mapped[...], mapped_column, ForeignKey, relationship(back_populates=...).
  • with Session(engine) as session: → add, delete, sửa thuộc tính → commit().
  • Truy vấn: session.scalars(select(X).where(...).order_by(...)), session.get(X, id), session.execute cho nhiều cột.
  • Cẩn thận N+1: dùng selectinload; đổi cấu trúc bảng bằng Alembic.

Bài tập

Bài 1. Tác giả kèm số sách

Dựng lại model ở mục 1 trong file mới, thêm 3 tác giả với tổng 6 cuốn, rồi in mỗi tác giả kèm số sách, sắp theo số sách giảm dần, kể cả tác giả chưa có sách nào.

Xem đáp án 
from sqlalchemy import ForeignKey, create_engine, func, select
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column, relationship


class Base(DeclarativeBase):
    pass


class TacGia(Base):
    __tablename__ = "tac_gia"
    id: Mapped[int] = mapped_column(primary_key=True)
    ten: Mapped[str]
    sach: Mapped[list["Sach"]] = relationship(back_populates="tac_gia")


class Sach(Base):
    __tablename__ = "sach"
    id: Mapped[int] = mapped_column(primary_key=True)
    ten: Mapped[str]
    nam: Mapped[int]
    tac_gia_id: Mapped[int] = mapped_column(ForeignKey("tac_gia.id"))
    tac_gia: Mapped[TacGia] = relationship(back_populates="sach")


engine = create_engine("sqlite://")              # CSDL trong RAM
Base.metadata.create_all(engine)
with Session(engine) as s:
    s.add_all([
        TacGia(ten="Nguyễn Nhật Ánh", sach=[Sach(ten="Mắt biếc", nam=1990), Sach(ten="Cho tôi xin một vé đi tuổi thơ", nam=2008),
                                            Sach(ten="Tôi thấy hoa vàng trên cỏ xanh", nam=2010)]),
        TacGia(ten="Nguyễn Du", sach=[Sach(ten="Truyện Kiều", nam=1820)]),
        TacGia(ten="Xuân Quỳnh"),
        TacGia(ten="Vũ Trọng Phụng", sach=[Sach(ten="Số đỏ", nam=1936), Sach(ten="Giông tố", nam=1936)]),
    ])
    s.commit()
    so_sach = func.count(Sach.id).label("so_sach")
    q = select(TacGia.ten, so_sach).outerjoin(TacGia.sach).group_by(TacGia.id).order_by(so_sach.desc(), TacGia.ten)
    for ten, n in s.execute(q):
        print(f"{ten:<16}{n}")
Nguyễn Nhật Ánh 3
Vũ Trọng Phụng  2
Nguyễn Du       1
Xuân Quỳnh      0

outerjoin là LEFT JOIN: giữ tác giả chưa có sách. func.count(Sach.id) đếm sách thật (bỏ NULL), nên Xuân Quỳnh được 0 chứ không phải 1.

Bài 2. Tìm sách theo từ khóa

Viết hàm tim_sach(session, tu_khoa, tu_nam=None) tìm sách có tên chứa từ khóa (không phân biệt hoa thường), lọc thêm theo năm nếu có, sắp theo năm.

Xem đáp án 
# (minh họa) dùng model và dữ liệu của bài 1
def tim_sach(session: Session, tu_khoa: str, tu_nam: int | None = None) -> list[Sach]:
    q = select(Sach).where(Sach.ten.ilike(f"%{tu_khoa}%"))
    if tu_nam is not None:
        q = q.where(Sach.nam >= tu_nam)              # ghép thêm điều kiện khi cần
    return list(session.scalars(q.order_by(Sach.nam)))


with Session(engine) as s:
    print([x.ten for x in tim_sach(s, "tôi")])
    print([x.ten for x in tim_sach(s, "tôi", tu_nam=2009)])
['Cho tôi xin một vé đi tuổi thơ', 'Tôi thấy hoa vàng trên cỏ xanh']
['Tôi thấy hoa vàng trên cỏ xanh']

Ghép điều kiện từng bước bằng q = q.where(...) là điểm mạnh của SQLAlchemy so với tự nối chuỗi SQL, và vẫn an toàn trước SQL injection vì từ khóa được truyền dưới dạng tham số. Lưu ý: SQLite chỉ so sánh không phân biệt hoa thường cho chữ cái ASCII, nên "TÔI" viết hoa có dấu sẽ không khớp "tôi"; PostgreSQL thì xử lý đúng với ILIKE.

Nguồn tham khảo: SQLAlchemy Unified Tutorial; ORM Quick Start; Relationship Loading Techniques; Alembic.

Bài tập thực hành

  1. Viết model TacGia và Sach (một – nhiều), thêm dữ liệu và in mỗi tác giả kèm số sách.
  2. Viết hàm tìm sách theo từ khóa trong tên, không phân biệt hoa thường, sắp theo năm.

Làm xong bài tập mới chuyển sang bài tiếp theo: tự viết code là cách duy nhất để nhớ lâu.
