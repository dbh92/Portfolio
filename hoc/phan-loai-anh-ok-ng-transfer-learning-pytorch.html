Phân loại ảnh OK/NG bằng transfer learning với PyTorch

Tinh chỉnh ResNet đã huấn luyện trên ImageNet với vài trăm ảnh: augmentation hợp lý, huấn luyện hai giai đoạn và xuất ONNX.

HF
Ban biên tập HọcFree11/09/20263 phút đọc

Học xong bài này, bạn sẽ

  • Tinh chỉnh mô hình có sẵn với ít dữ liệu
  • Đánh giá bằng ma trận nhầm lẫn
  • Xuất mô hình ONNX

Nên học trước: Overfitting và chia train/val/test

Nội dung bài viết
  1. Chuẩn bị dữ liệu
  2. Dataset và augmentation
  3. Thay "đầu" của mô hình
  4. Huấn luyện hai giai đoạn
  5. Đánh giá đúng kiểu nhà máy
  6. Xuất ONNX để triển khai

Huấn luyện một CNN từ đầu cần rất nhiều dữ liệu. Transfer learning tận dụng mô hình đã học trên hàng triệu ảnh (ImageNet), chỉ cần tinh chỉnh lại với vài trăm ảnh của bạn. Đây là cách nhanh nhất để có một bộ phân loại OK/NG dùng được.

Chuẩn bị dữ liệu

data/
  train/ok/  train/ng/
  val/ok/    val/ng/

Cắt ảnh về đúng vùng cần kiểm tra (ROI) trước khi đưa vào mô hình. Mô hình nhìn ROI 224×224 sẽ học tốt hơn nhiều so với cả khung hình 5 megapixel bị thu nhỏ.

Dataset và augmentation

import torch
from torch import nn
from torchvision import datasets, models, transforms

weights = models.ResNet18_Weights.DEFAULT
mean, std = [0.485, 0.456, 0.406], [0.229, 0.224, 0.225]   # chuẩn hóa ImageNet

train_tf = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.RandomHorizontalFlip(),
    transforms.RandomRotation(5),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])
val_tf = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])

train_ds = datasets.ImageFolder("data/train", train_tf)
val_ds = datasets.ImageFolder("data/val", val_tf)
print(train_ds.classes)       # ['ng', 'ok'] theo thứ tự chữ cái
train_dl = torch.utils.data.DataLoader(train_ds, batch_size=32, shuffle=True)
val_dl = torch.utils.data.DataLoader(val_ds, batch_size=64)

Chỉ dùng augmentation có thể xảy ra thật. Nếu sản phẩm luôn đúng chiều trên băng tải, đừng xoay 90°; nếu lỗi phụ thuộc màu, đừng đổi màu mạnh.

Thay "đầu" của mô hình

device = "cuda" if torch.cuda.is_available() else "cpu"
model = models.resnet18(weights=weights)
model.fc = nn.Linear(model.fc.in_features, len(train_ds.classes))   # 2 lớp
model = model.to(device)

Huấn luyện hai giai đoạn

def run_epoch(loader, train):
    model.train(train)
    correct, total = 0, 0
    with torch.set_grad_enabled(train):
        for x, y in loader:
            x, y = x.to(device), y.to(device)
            out = model(x)
            loss = criterion(out, y)
            if train:
                optimizer.zero_grad(); loss.backward(); optimizer.step()
            correct += (out.argmax(1) == y).sum().item()
            total += len(y)
    return correct / total

criterion = nn.CrossEntropyLoss()

# Giai đoạn 1: đóng băng thân mạng, chỉ học lớp cuối
for p in model.parameters():
    p.requires_grad = False
for p in model.fc.parameters():
    p.requires_grad = True
optimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-3)
for ep in range(5):
    print("stage1", ep, run_epoch(train_dl, True), run_epoch(val_dl, False))

# Giai đoạn 2: mở toàn bộ, learning rate nhỏ
for p in model.parameters():
    p.requires_grad = True
optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
for ep in range(10):
    print("stage2", ep, run_epoch(train_dl, True), run_epoch(val_dl, False))

Đánh giá đúng kiểu nhà máy

Đừng chỉ nhìn accuracy. Tính tỷ lệ lọt lỗi và loại nhầm trên tập val, chọn ngưỡng xác suất NG phù hợp (xem precision, recall và ma trận nhầm lẫn). Với dữ liệu NG quá ít, cân nhắc anomaly detection.

Xuất ONNX để triển khai

model.eval()
torch.onnx.export(model.cpu(), torch.randn(1, 3, 224, 224), "ok_ng.onnx",
                  input_names=["input"], output_names=["logits"])

Khi chạy ONNX ở nơi khác, nhớ áp dụng đúng tiền xử lý: resize 224, RGB, chia 255, chuẩn hóa mean/std ImageNet.

Bài tập thực hành

  1. Huấn luyện trên bộ dữ liệu của bạn (hoặc dataset mẫu), báo cáo recall lớp NG và số ảnh NG bị lọt.

Làm xong bài tập mới chuyển sang bài tiếp theo: tự viết code là cách duy nhất để nhớ lâu.
