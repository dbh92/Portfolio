Git & GitHub từ A đến Z: hướng dẫn chi tiết cho người mới

Git là công cụ mọi lập trình viên đều phải dùng. Bài viết hướng dẫn từ cài đặt, commit, branch đến đẩy code lên GitHub.

Bạn đã bao giờ đặt tên file kiểu baitap_final.html, baitap_final_v2.html, baitap_final_that_su.html chưa? Git sinh ra để giải quyết chính vấn đề đó. Nó lưu lại toàn bộ lịch sử thay đổi của dự án, cho phép quay về bất kỳ phiên bản nào và làm việc nhóm mà không ghi đè code của nhau.

Git và GitHub khác nhau thế nào?

  • Git là phần mềm quản lý phiên bản, chạy trên máy tính của bạn.
  • GitHub là website lưu trữ kho Git trên mạng, giúp chia sẻ và cộng tác. Ngoài ra còn có GitLab, Bitbucket…

Bước 1: Cài đặt và cấu hình

Tải Git tại git-scm.com, cài đặt rồi mở Terminal (hoặc Git Bash trên Windows):

git config --global user.name "Nguyen Van A"
git config --global user.email "email@cua-ban.com"
git --version

Bước 2: Tạo kho (repository) đầu tiên

mkdir du-an-dau-tien
cd du-an-dau-tien
git init

Lệnh git init tạo thư mục ẩn .git, nơi lưu toàn bộ lịch sử.

Bước 3: Vòng đời add → commit

Hãy hình dung Git có ba khu vực: thư mục làm việc, khu vực chờ (staging) và lịch sử (repository).

git status                 # xem file nào đã thay đổi
git add index.html         # đưa file vào khu vực chờ
git add .                  # hoặc đưa tất cả
git commit -m "Thêm trang chủ"
git log --oneline          # xem lịch sử commit
Viết commit message rõ ràng, ở thể mệnh lệnh: "Thêm form đăng nhập", "Sửa lỗi hiển thị trên mobile". Sau 6 tháng bạn sẽ cảm ơn chính mình.

Bước 4: Làm việc với nhánh (branch)

Nhánh cho phép bạn thử nghiệm tính năng mới mà không ảnh hưởng code chính.

git switch -c tinh-nang-moi    # tạo và chuyển sang nhánh mới
# ... sửa code, commit ...
git switch main
git merge tinh-nang-moi        # gộp vào nhánh chính

Bước 5: Đẩy code lên GitHub

  1. Đăng ký tài khoản tại github.com.
  2. Bấm New repository, đặt tên và tạo kho trống.
  3. Kết nối và đẩy code:
git remote add origin https://github.com/ten-ban/du-an-dau-tien.git
git branch -M main
git push -u origin main

Từ lần sau, bạn chỉ cần git push sau mỗi lần commit. Để lấy code mới nhất từ GitHub về, dùng git pull.

Bảng lệnh cần nhớ

LệnhÝ nghĩa
git clone <url>Tải một kho có sẵn về máy
git diffXem chi tiết thay đổi chưa commit
git restore <file>Hủy thay đổi chưa commit của file
git log --oneline --graphXem lịch sử dạng cây
git stashCất tạm thay đổi để chuyển nhánh

File .gitignore

Không phải file nào cũng nên đưa lên Git. Tạo file .gitignore để loại trừ thư mục thư viện, file mật khẩu, file tạm:

node_modules/
.env
*.log
.DS_Store

Chỉ cần thành thạo các lệnh trong bài này là bạn đã đủ dùng cho 90% công việc hằng ngày. Phần còn lại như rebase, cherry-pick… hãy học dần khi thực sự cần.
