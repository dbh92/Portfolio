Đây là dự án tổng kết chặng PLC / Robot / MES: bạn ghép mọi thứ của chặng thành một chương trình trạm vision hoàn chỉnh, chạy được ngay trên máy tính với một PLC mô phỏng. Trạm nhận trigger qua Modbus TCP, "chụp" ảnh, kiểm tra bằng OpenCV, trả kết quả và số liệu cho PLC theo đúng trình tự bắt tay, lưu kết quả vào SQLite và ảnh NG vào thư mục theo ngày, ghi log đầy đủ ra file, và tự đứng dậy khi PLC khởi động lại giữa chừng. Khi xong, bạn có một khung chương trình dùng lại được cho trạm thật: chỉ cần thay camera giả bằng camera thật, thay PLC giả bằng IP của PLC thật.

Mục tiêu dự ánNhận trigger qua Modbus TCP; xử lý ảnh, trả kết quả, lưu dữ liệu; chạy ổn định qua sự cố (mất kết nối, camera lỗi) và để lại log đủ để người khác chẩn đoán mà không cần hỏi bạn.

1. Đề bài

Một khay chứa 4 chốt kim loại đi qua trạm kiểm tra. PLC dừng khay dưới camera và bật trigger. Trạm vision phải kiểm tra:

  • Đủ 4 chốt → OK.
  • Thiếu chốt, thừa chốt, hoặc có chốt sai kích thước (vỡ, cong) → NG kèm mã lỗi.
  • Không chụp được ảnh → LỖI (PLC xử lý như NG và báo động), trạm phải tự chạy tiếp ở sản phẩm sau.

Trong mô phỏng, PLC đưa 12 khay qua trạm, trong đó có 1 khay thiếu chốt, 1 khay có chốt vỡ, 1 khay thừa chốt, 1 lần camera không trả ảnh, và PLC "mất điện" khoảng 1 giây sau khay thứ 6. Chương trình phải tự kết thúc sau 12 khay và in tổng kết.

Bảng địa chỉ Modbus (địa chỉ giao thức, bắt đầu từ 0), cùng quy ước với bài "Modbus TCP bằng Python với pymodbus":

3. Kiến thức sử dụng

  • I/O số và handshake với PLC: trình tự TRIGGER → BUSY → kết quả → DONE → TRIGGER tắt → READY; bắt sườn; timeout hai phía.
  • Modbus TCP bằng Python với pymodbus: PLC giả bằng SimDevice, ModbusTcpClient, isError(), float32 qua hai thanh ghi, vòng lặp kết nối lại.
  • Lưu kết quả và ảnh NG: SQLite, thư mục, dọn ổ đĩa: WAL, tham số theo tên, thư mục theo ngày, thread ghi nền.
  • Chặng OpenCV và Image Processing: Otsu, connectedComponentsWithStats, lọc theo diện tích; tổ chức pipeline có cấu hình bằng dataclass.
  • Python: logging với RotatingFileHandler, threading, queue.

def cai_log(thu_muc):
    """Log ra file xoay vòng 1 MB x 5 file. Gắn vào root để nhận cả log của pymodbus."""
    goc = logging.getLogger()
    for h in list(goc.handlers):                            # chạy lại nhiều lần không bị nhân đôi log
        if isinstance(h, RotatingFileHandler):
            goc.removeHandler(h)
            h.close()
    fh = RotatingFileHandler(Path(thu_muc) / "tram.log", maxBytes=1_000_000, backupCount=5, encoding="utf-8")
    fh.setFormatter(logging.Formatter("%(asctime)s.%(msecs)03d %(levelname)-7s %(name)-8s %(message)s",
                                      "%Y-%m-%d %H:%M:%S"))
    goc.addHandler(fh)
    goc.setLevel(logging.INFO)
    return logging.getLogger("tram")

Phần 2: PLC giả. Server giống bài Modbus; "chương trình PLC" chạy trong thread riêng, sau khay thứ 6 thì tắt server 1 giây rồi bật lại với bộ nhớ trắng.

# ===== plc_gia.py — PLC mô phỏng: Modbus server + "chương trình PLC" =====
class PlcGia:
    def __init__(self, port):
        self.port = port

    def bat(self):
        self._da_nghe = threading.Event()
        self._thread = threading.Thread(target=lambda: asyncio.run(self._main()), daemon=True)
        self._thread.start()
        if not self._da_nghe.wait(timeout=3):
            raise RuntimeError("PLC giả không khởi động được")

    async def _main(self):
        self.loop = asyncio.get_running_loop()
        bo_nho = SimDevice(id=1, simdata=(
            [SimData(0, count=16, values=False, datatype=DataType.BITS)],
            [SimData(0, count=16, values=False, datatype=DataType.BITS)],
            [SimData(0, count=32, values=0, datatype=DataType.REGISTERS)],
            [SimData(0, count=16, values=0, datatype=DataType.REGISTERS)],
        ))
        self.server = ModbusTcpServer(bo_nho, address=("127.0.0.1", self.port))
        await self.server.serve_forever(background=True)
        self._da_nghe.set()
        await self.server.serving

    def tat(self):
        asyncio.run_coroutine_threadsafe(self.server.shutdown(), self.loop).result(timeout=3)
        self._thread.join(timeout=3)

    def _goi(self, coro):
        return asyncio.run_coroutine_threadsafe(coro, self.loop).result(timeout=2)

    def doc_coil(self, dc):
        return self._goi(self.server.async_getValues(1, 1, dc, 1))[0]

    def ghi_coil(self, dc, v):
        self._goi(self.server.async_setValues(1, 5, dc, [bool(v)]))

    def doc_hr(self, dc, n=1):
        return self._goi(self.server.async_getValues(1, 3, dc, n))

    def ghi_hr(self, dc, gia_tri):
        self._goi(self.server.async_setValues(1, 16, dc, list(gia_tri)))


def chuong_trinh_plc(plc, so_sp, ket_qua_plc, khoi_dong_lai_sau=6, timeout_done=3.0):
    """Mỗi sản phẩm: chờ READY → ghi mã SP + số chu kỳ → TRIGGER → chờ DONE → đọc kết quả → tắt TRIGGER."""
    log = logging.getLogger("plc_gia")

    def cho(dieu_kien, timeout):
        han = time.monotonic() + timeout
        while time.monotonic() < han:
            if dieu_kien():
                return True
            time.sleep(0.005)
        return False

    for k in range(1, so_sp + 1):
        if not cho(lambda: plc.doc_coil(READY), 5.0):
            log.error("SP%d: vision không READY", k)
            ket_qua_plc.append((k, "KHONG_READY"))
            continue
        plc.ghi_hr(HR_MA_SP, [101, k])                 # mã sản phẩm 101, số chu kỳ k
        plc.ghi_coil(TRIGGER, 1)
        if cho(lambda: plc.doc_coil(DONE), timeout_done):
            kq, k_tra, so_vat, ma_loi = plc.doc_hr(HR_KQ, 4)
            if k_tra != k:
                ket_qua_plc.append((k, "LECH_CHU_KY"))
            else:
                ket_qua_plc.append((k, {KQ_OK: "OK", KQ_NG: "NG", KQ_LOI: "LOI"}.get(kq, "KQ_SAI")))
        else:
            log.error("SP%d: TIMEOUT chờ DONE → đẩy ra như NG", k)
            ket_qua_plc.append((k, "TIMEOUT"))
        plc.ghi_coil(TRIGGER, 0)
        cho(lambda: not plc.doc_coil(DONE), 2.0)
        time.sleep(0.03)                               # băng tải đưa sản phẩm kế tiếp vào
        if k == khoi_dong_lai_sau:
            log.warning("Mô phỏng PLC khởi động lại (mất 1 s)")
            plc.tat()
            time.sleep(1.0)
            plc.bat()

Phần 3: camera giả và thuật toán kiểm tra. Camera sinh ảnh khay với nhiễu, kịch bản lỗi theo số chu kỳ; thuật toán không biết kịch bản, chỉ nhìn ảnh. Thử riêng thuật toán trước khi nối với PLC:

# ===== camera_gia.py + kiem_tra.py =====
# Kịch bản (vision KHÔNG biết trước): số chu kỳ → kiểu sản phẩm
KICH_BAN = {3: "thieu", 5: "vo", 8: "camera_loi", 10: "thua"}
VI_TRI = [(160, 160), (480, 160), (160, 330), (480, 330), (320, 245)]


class CameraGia:
    def chup(self, chu_ky):
        kieu = KICH_BAN.get(chu_ky, "ok")
        if kieu == "camera_loi":
            return None                                    # giống cap.read() trả về False
        rng = np.random.default_rng(chu_ky)
        anh = rng.normal(45, 6, (480, 640)).clip(0, 255).astype(np.uint8)
        so = {"thieu": 3, "thua": 5}.get(kieu, 4)
        for i, (x, y) in enumerate(VI_TRI[:so]):
            r = 15 if (kieu == "vo" and i == 1) else 30    # "vỡ": một vật chỉ còn mảnh nhỏ
            cv2.circle(anh, (x, y), r, int(rng.integers(190, 220)), -1)
        return anh


def kiem_tra(anh, cfg):
    """Trả về (ket_qua, ma_loi, so_vat_hop_le, dien_tich_tb_mm2)."""
    if anh is None:
        return KQ_LOI, "loi_camera", 0, 0.0
    mo = cv2.GaussianBlur(anh, (5, 5), 0)
    _, nhi_phan = cv2.threshold(mo, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    n, _, stats, _ = cv2.connectedComponentsWithStats(nhi_phan)
    dien_tich = stats[1:, cv2.CC_STAT_AREA]
    dien_tich = dien_tich[dien_tich > 100]                 # bỏ đốm nhiễu
    lo, hi = cfg.dien_tich_px
    hop_le = dien_tich[(dien_tich >= lo) & (dien_tich <= hi)]
    tb_mm2 = round(float(hop_le.mean()) * cfg.mm_moi_px ** 2, 3) if len(hop_le) else 0.0
    if len(hop_le) != len(dien_tich):
        return KQ_NG, "sai_kich_thuoc", len(hop_le), tb_mm2
    if len(hop_le) < cfg.so_vat_dung:
        return KQ_NG, "thieu_vat", len(hop_le), tb_mm2
    if len(hop_le) > cfg.so_vat_dung:
        return KQ_NG, "thua_vat", len(hop_le), tb_mm2
    return KQ_OK, "", len(hop_le), tb_mm2

Phần 4: lưu trữ. Thu gọn từ bài SQLite: một bảng, chỉ mục thời gian, thread ghi nền, dọn ảnh cũ lúc khởi động.

# ===== luu_tru.py — SQLite + ảnh NG, ghi trong thread nền =====
SCHEMA = """
CREATE TABLE IF NOT EXISTS kiem_tra (
    id INTEGER PRIMARY KEY, thoi_gian TEXT NOT NULL, chu_ky INTEGER, ma_sp INTEGER,
    ket_qua TEXT NOT NULL CHECK (ket_qua IN ('OK', 'NG', 'LOI')), ma_loi TEXT,
    so_vat INTEGER, dien_tich_tb REAL, tg_xu_ly_ms REAL, duong_dan_anh TEXT);
CREATE INDEX IF NOT EXISTS ix_thoi_gian ON kiem_tra(thoi_gian);
"""
SQL_THEM = """INSERT INTO kiem_tra (thoi_gian, chu_ky, ma_sp, ket_qua, ma_loi, so_vat, dien_tich_tb, tg_xu_ly_ms,
              duong_dan_anh) VALUES (:thoi_gian, :chu_ky, :ma_sp, :ket_qua, :ma_loi, :so_vat, :dien_tich_tb,
              :tg_xu_ly_ms, :duong_dan_anh)"""


def mo_csdl(duong_dan):
    con = sqlite3.connect(duong_dan, timeout=5.0)
    con.execute("PRAGMA journal_mode=WAL")
    con.execute("PRAGMA synchronous=NORMAL")
    con.executescript(SCHEMA)
    return con


def don_anh_cu(thu_muc_anh, giu_ngay, hom_nay=None):
    """Xóa thư mục ảnh YYYY-MM-DD cũ hơn giu_ngay (chạy lúc khởi động)."""
    han = (hom_nay or date.today()) - timedelta(days=giu_ngay)
    da_xoa = 0
    for p in Path(thu_muc_anh).glob("????-??-??"):
        try:
            if p.is_dir() and date.fromisoformat(p.name) < han:
                for f in p.iterdir():
                    f.unlink()
                p.rmdir()
                da_xoa += 1
        except ValueError:
            continue                                   # tên giống mẫu nhưng không phải ngày hợp lệ
    return da_xoa


class GhiNen(threading.Thread):
    def __init__(self, thu_muc, kich_thuoc=200):
        super().__init__(daemon=True, name="ghi_nen")
        self.thu_muc = Path(thu_muc)
        self.hang_doi = queue.Queue(maxsize=kich_thuoc)
        self.so_ghi = self.so_anh = self.so_bo = 0
        self.log = logging.getLogger("luu_tru")

    def gui(self, ban_ghi, anh=None):
        try:
            self.hang_doi.put_nowait((ban_ghi, anh))
        except queue.Full:
            self.so_bo += 1
            self.log.error("Hàng đợi ghi đầy, bỏ bản ghi chu kỳ %s", ban_ghi["chu_ky"])

    def dung(self):
        self.hang_doi.put((None, None))
        self.join(timeout=10)

    def run(self):
        con = mo_csdl(self.thu_muc / "ket_qua.db")
        cho, t_commit = 0, time.monotonic()
        while True:
            try:
                ban_ghi, anh = self.hang_doi.get(timeout=0.5)
                if ban_ghi is None:
                    break
                if anh is not None:
                    dich = self.thu_muc / "anh" / ban_ghi["duong_dan_anh"]
                    dich.parent.mkdir(parents=True, exist_ok=True)
                    if cv2.imwrite(str(dich), anh):
                        self.so_anh += 1
                    else:
                        self.log.error("Không ghi được ảnh %s", dich)
                        ban_ghi["duong_dan_anh"] = None
                con.execute(SQL_THEM, ban_ghi)
                self.so_ghi += 1
                cho += 1
            except queue.Empty:
                pass
            except Exception:                          # thread ghi không bao giờ được chết âm thầm
                self.log.exception("Lỗi khi ghi dữ liệu")
            if cho and (cho >= 50 or time.monotonic() - t_commit >= 0.5):
                con.commit()
                cho, t_commit = 0, time.monotonic()
        con.commit()
        con.close()

Phần 5: trạm vision. Vòng lặp chính: kết nối (lại) → hỏi vòng TRIGGER → bắt sườn → một chu kỳ → heartbeat. Một chu kỳ: BUSY → đọc mã SP và số chu kỳ → chụp → kiểm tra → ghi kết quả (một lệnh) → DONE → gửi bản ghi cho thread nền → chờ TRIGGER tắt (có timeout) → READY.

# ===== tram.py — vòng lặp chính của trạm vision =====
class TramVision:
    def __init__(self, cfg, camera, ghi):
        self.cfg, self.camera, self.ghi = cfg, camera, ghi
        self.client = ModbusTcpClient(cfg.host, port=cfg.port, timeout=0.5, retries=1)
        self.log = logging.getLogger("tram")
        self.thong_ke = {"OK": 0, "NG": 0, "LOI": 0}
        self.cycle_ms = []
        self.so_lan_ket_noi = 0
        self.heartbeat, self.t_heartbeat = 0, 0.0

    # --- tiện ích Modbus: mọi phản hồi lỗi đều thành exception
    def _kiem(self, rr):
        if rr.isError():
            raise ModbusException(f"PLC trả lỗi: {rr}")
        return rr

    def _doc_trigger(self):
        return self._kiem(self.client.read_coils(TRIGGER, count=1, device_id=self.cfg.device_id)).bits[0]

    def _tin_hieu(self, ready, busy, done, error=False):
        self._kiem(self.client.write_coils(READY, [ready, busy, done, error], device_id=self.cfg.device_id))

    def _nhip_tim(self):
        if time.monotonic() - self.t_heartbeat >= 1.0:
            self.heartbeat = (self.heartbeat + 1) % 65536
            self._kiem(self.client.write_register(HR_HEARTBEAT, self.heartbeat, device_id=self.cfg.device_id))
            self.t_heartbeat = time.monotonic()

    # --- một chu kỳ kiểm tra
    def _mot_chu_ky(self):
        t0 = time.perf_counter()
        thoi_diem = datetime.now()
        self._tin_hieu(ready=False, busy=True, done=False)
        ma_sp, chu_ky = self._kiem(self.client.read_holding_registers(
            HR_MA_SP, count=2, device_id=self.cfg.device_id)).registers
        anh = self.camera.chup(chu_ky)
        kq, ma_loi, so_vat, dien_tich = kiem_tra(anh, self.cfg)
        regs = [kq, chu_ky, so_vat, MA_LOI[ma_loi]] + self.client.convert_to_registers(
            dien_tich, self.client.DATATYPE.FLOAT32)
        self._kiem(self.client.write_registers(HR_KQ, regs, device_id=self.cfg.device_id))   # kết quả trước
        self._tin_hieu(ready=False, busy=False, done=True, error=(kq == KQ_LOI))             # rồi mới DONE
        tg_ms = (time.perf_counter() - t0) * 1000

        ten_kq = {KQ_OK: "OK", KQ_NG: "NG", KQ_LOI: "LOI"}[kq]
        duong_dan = None
        if kq == KQ_NG:
            gio = thoi_diem.strftime("%H%M%S_%f")[:-3]                 # 094001_123 (đến ms)
            duong_dan = f"{thoi_diem:%Y-%m-%d}/{gio}_C{chu_ky:05d}_{ma_loi}.png"
        self.ghi.gui({"thoi_gian": thoi_diem.isoformat(timespec="milliseconds"), "chu_ky": chu_ky,
                      "ma_sp": ma_sp, "ket_qua": ten_kq, "ma_loi": ma_loi or None, "so_vat": so_vat,
                      "dien_tich_tb": dien_tich, "tg_xu_ly_ms": round(tg_ms, 2), "duong_dan_anh": duong_dan},
                     anh if kq == KQ_NG else None)
        self.thong_ke[ten_kq] += 1
        self.cycle_ms.append(tg_ms)
        muc = logging.WARNING if kq != KQ_OK else logging.INFO
        mo_ta = ten_kq + (f" ({ma_loi})" if ma_loi else "")
        self.log.log(muc, "Chu kỳ %d: %s, %d vật, %.1f ms", chu_ky, mo_ta, so_vat, tg_ms)
        print(f"Chu kỳ {chu_ky:2d}: {ten_kq:<3} {ma_loi:<15} {so_vat} vật")

        han = time.monotonic() + self.cfg.timeout_trigger_tat_s       # chờ PLC tắt TRIGGER
        trigger = True
        while trigger:
            if time.monotonic() > han:
                self.log.error("Chu kỳ %d: PLC không tắt TRIGGER sau %.1f s", chu_ky, self.cfg.timeout_trigger_tat_s)
                break
            time.sleep(self.cfg.chu_ky_doc_s)
            trigger = self._doc_trigger()
        self._tin_hieu(ready=True, busy=False, done=False)
        return trigger

    # --- vòng lặp chính
    def chay(self, so_chu_ky, thoi_han_s=30):
        trigger_truoc = False
        het_han = time.monotonic() + thoi_han_s
        tong = 0
        try:
            while tong < so_chu_ky and time.monotonic() < het_han:
                if not self.client.connected:
                    if not self.client.connect():
                        time.sleep(self.cfg.cho_ket_noi_lai_s)
                        continue
                    self.so_lan_ket_noi += 1
                    self.log.info("Kết nối PLC %s:%d (lần %d)", self.cfg.host, self.cfg.port, self.so_lan_ket_noi)
                    if self.so_lan_ket_noi > 1:
                        print("  ... đã kết nối lại PLC")
                    self._tin_hieu(ready=True, busy=False, done=False)  # PLC có thể vừa khởi động lại
                    trigger_truoc = False
                try:
                    trigger = self._doc_trigger()
                    if trigger and not trigger_truoc:
                        trigger = self._mot_chu_ky()
                        tong += 1
                    trigger_truoc = trigger
                    self._nhip_tim()
                    time.sleep(self.cfg.chu_ky_doc_s)
                except ModbusException as e:
                    self.log.warning("Mất kết nối PLC (%s)", type(e).__name__)
                    print("  ... mất kết nối PLC, đang thử lại")
                    self.client.close()
                    time.sleep(self.cfg.cho_ket_noi_lai_s)
        finally:
            if self.client.connected:
                try:
                    self._tin_hieu(ready=False, busy=False, done=False)   # tắt READY khi dừng
                except ModbusException:
                    pass
            self.client.close()
            self.log.info("Dừng trạm sau %d chu kỳ", tong)

7. Mở rộng

  • Chạy dài (soak test): đặt so_sp=2000, khoảng cách giữa các khay 10 ms; theo dõi RAM, số dòng log, thời gian xử lý lớn nhất. Trạm thật phải chạy hàng tuần không khởi động lại.
  • Camera thật: thay CameraGia bằng lớp đọc từ cv2.VideoCapture hoặc SDK của hãng, giữ nguyên hàm chup(); trả None khi lỗi để phần còn lại không đổi.
  • Đổi công thức (recipe): đọc HR 0 (mã sản phẩm) để chọn bộ tham số từ file JSON; mã lạ → LỖI, không đoán.
  • Gửi tọa độ cho robot: thêm kênh TCP socket như bài "TCP socket: gửi kết quả và tọa độ cho robot", gửi tâm từng chốt kèm số thứ tự và chờ ACK.
  • Báo cáo ca: script đọc SQLite in yield theo giờ, top lỗi, đường dẫn ảnh NG gần nhất; xuất CSV cho MES.
  • Dọn theo dung lượng: thêm lớp dọn theo shutil.disk_usage chạy mỗi giờ trong thread nền, báo động khi phải xóa sớm.
  • Watchdog: một thread kiểm tra vòng lặp chính có còn "nhịp" không (ví dụ thời điểm đọc TRIGGER gần nhất); quá 5 s thì ghi log CRITICAL và tự khởi động lại chương trình.

Tóm tắt

  • Một trạm vision hoàn chỉnh = thuật toán + bắt tay PLC + lưu dữ liệu + log + xử lý sự cố; phần "không phải thuật toán" chiếm phần lớn code và quyết định trạm có chạy được ở nhà máy hay không.
  • Tách thuật toán khỏi giao tiếp và lưu trữ để thử riêng từng phần; PLC giả và camera giả cho phép thử mọi sự cố ngay trên bàn làm việc.
  • Mọi chỗ chờ đều có timeout, mọi sự cố đều có log, mọi kết quả đều có số chu kỳ để đối chiếu.
