VS Code là trình soạn thảo được dùng nhiều nhất cho Python và AI: miễn phí, nhẹ, chạy trên Windows/Linux/macOS, hỗ trợ notebook, debug, kết nối máy từ xa. Bài này hướng dẫn thiết lập VS Code tối ưu cho dự án Computer Vision.

Extension cần có

  • Python và Pylance (Microsoft): gợi ý code, kiểm tra kiểu, chạy và debug.
  • Jupyter: mở và chạy file .ipynb ngay trong VS Code.
  • Ruff: kiểm tra lỗi và định dạng code tự động.
  • Remote - SSH: viết code trên laptop nhưng chạy trên máy có GPU hoặc máy công nghiệp.
  • GitLens (tùy chọn): xem lịch sử thay đổi từng dòng code.

Chọn đúng môi trường Python

Lỗi phổ biến nhất: cài thư viện vào môi trường ảo nhưng VS Code chạy bằng Python hệ thống, dẫn tới ModuleNotFoundError.

  1. Ctrl+Shift+P → Python: Select Interpreter.
  2. Chọn interpreter trong thư mục .venv của dự án.
  3. Terminal mới mở trong VS Code sẽ tự kích hoạt môi trường đó.

Debug thay vì in ra màn hình

  • Bấm vào lề trái để đặt breakpoint, nhấn F5 để chạy debug.
  • Khi dừng, rê chuột lên biến để xem giá trị; cửa sổ Debug Console cho phép chạy lệnh như img.shape, contours[0].size.
  • Breakpoint có điều kiện (chuột phải vào breakpoint): chỉ dừng khi area < 100, rất tiện khi xử lý hàng nghìn ảnh.

Cấu hình chạy với tham số trong .vscode/launch.json:

{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Kiểm tra thư mục ảnh",
      "type": "debugpy",
      "request": "launch",
      "program": "${workspaceFolder}/src/inspect_folder.py",
      "args": ["--input", "data/test", "--save-ng"],
      "console": "integratedTerminal"
    }
  ]
}

Xem ảnh trung gian khi debug

Trong notebook, hiển thị ảnh bằng matplotlib. Khi debug file .py, ghi ảnh trung gian ra thư mục tạm (cv2.imwrite("debug/02_threshold.png", th)) và mở song song trong VS Code: thấy ngay bước nào xử lý sai.

Làm việc trên máy GPU từ xa

Với Remote - SSH, bạn mở thư mục trên máy chủ GPU như đang ở máy mình: chỉnh code, chạy huấn luyện, debug, xem ảnh kết quả. Không cần copy file qua lại và không cần màn hình trên máy chủ.
