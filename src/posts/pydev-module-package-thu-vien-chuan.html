Một file 2.000 dòng rất khó đọc, khó sửa và không ai dám đụng vào. Người đi làm chia code thành nhiều file nhỏ, mỗi file một nhiệm vụ: đó là module. Nhiều module gom thành thư mục là package. Python còn kèm sẵn hàng trăm module chuẩn, gọi là "pin có sẵn" (batteries included). Bài này dạy cả hai: tự tổ chức code và dùng thư viện chuẩn.

1. Module là một file .py

Tạo thư mục dự án:

chi_tieu/
├── tien_te.py     ← hàm xử lý tiền
└── main.py        ← chương trình chính

File tien_te.py:

"""Hàm tiện ích định dạng và đọc số tiền."""


def vnd(so: float) -> str:
    """1234567 → '1.234.567đ'"""
    return f"{so:,.0f}".replace(",", ".") + "đ"


def doc_so_tien(chuoi: str) -> int:
    """'1.234.567' hoặc '1,234,567đ' → 1234567"""
    sach = chuoi.replace(".", "").replace(",", "").replace("đ", "").strip()
    return int(sach)


if __name__ == "__main__":
    assert vnd(1234567) == "1.234.567đ"
    assert doc_so_tien("1.234.567đ") == 1234567
    print("tien_te.py: kiểm tra đạt")
tien_te.py: kiểm tra đạt

File main.py cùng thư mục:

# (minh họa) cần file tien_te.py ở cùng thư mục
import tien_te
from tien_te import vnd

so = tien_te.doc_so_tien("2.500.000")
print(vnd(so * 3))
PS D:\chi_tieu> python main.py
7.500.000đ

2. Các cách import

import math                          # dùng: math.sqrt(16)
from math import sqrt, pi            # dùng thẳng: sqrt(16)
import datetime as dt                # đặt bí danh: dt.date.today()
from collections import Counter as C # bí danh cho tên được import

print(math.sqrt(16), sqrt(25), round(pi, 4))
4.0 5.0 3.1416
  • import module giữ tên module khi gọi: đọc code biết ngay hàm từ đâu.
  • from module import ten gọn hơn khi dùng nhiều lần.
  • Tránh from module import *: không biết tên nào từ đâu và dễ ghi đè tên của bạn.
  • Theo PEP 8, đặt import ở đầu file, theo thứ tự: thư viện chuẩn, thư viện bên ngoài, module của dự án; mỗi nhóm cách một dòng trống.

3. if __name__ == "__main__"

Mỗi module có biến đặc biệt __name__. Khi bạn chạy trực tiếp python tien_te.py, __name__ là "__main__"; khi file được import, __name__ là tên module ("tien_te"). Nhờ vậy khối if __name__ == "__main__": chỉ chạy khi chạy trực tiếp: hợp để đặt phần tự kiểm tra hoặc chương trình chính, mà không bị chạy khi module khác import.

Đừng đặt tên file trùng module chuẩnTạo file random.py hay math.py trong dự án thì import random sẽ nạp file của bạn thay vì module chuẩn, và lỗi rất khó hiểu kiểu AttributeError: module 'random' has no attribute 'randint'. Python tìm module trong thư mục của script trước tiên.

random, math, statistics

import math
import random
import statistics

random.seed(7)                         # cố định để kết quả lặp lại được

Ví dụ lương cho thấy vì sao cần trung vị: một người lương 95 kéo trung bình lên 29,5 trong khi đa số chỉ khoảng 15–18. random phù hợp cho trò chơi và mô phỏng; sinh mật khẩu hay mã bảo mật thì phải dùng module secrets.

Tra cứu nhanhTrong REPL, help(math.gcd) in tài liệu của hàm, dir(math) liệt kê mọi tên trong module. Danh sách đầy đủ module chuẩn nằm ở docs.python.org/3/library.

Tóm tắt

  • Module = file .py; package = thư mục có __init__.py.
  • import x, from x import y, import x as z; tránh import *.
  • if __name__ == "__main__": cho phần chỉ chạy khi chạy trực tiếp.
  • Không đặt tên file trùng module chuẩn.
  • datetime, random, math, statistics, collections có sẵn, không cần cài.

Bài tập

Bài 1. Đếm ngày đến sinh nhật

Viết module ngay_thang.py có hàm so_ngay_den_sinh_nhat(ngay_sinh, hom_nay) trả số ngày đến sinh nhật kế tiếp (0 nếu là hôm nay), kèm khối tự kiểm tra.

Xem đáp án 
"""ngay_thang.py: hàm xử lý ngày tháng."""
from datetime import date


def so_ngay_den_sinh_nhat(ngay_sinh: date, hom_nay: date) -> int:
    """Số ngày từ hom_nay đến sinh nhật kế tiếp (0 nếu đúng hôm nay)."""
    try:
        sn = ngay_sinh.replace(year=hom_nay.year)
    except ValueError:                       # sinh 29/2, năm nay không nhuận
        sn = date(hom_nay.year, 3, 1)
    if sn < hom_nay:
        try:
            sn = ngay_sinh.replace(year=hom_nay.year + 1)
        except ValueError:
            sn = date(hom_nay.year + 1, 3, 1)
    return (sn - hom_nay).days


if __name__ == "__main__":
    hom_nay = date(2026, 10, 29)
    assert so_ngay_den_sinh_nhat(date(2000, 10, 29), hom_nay) == 0
    assert so_ngay_den_sinh_nhat(date(2000, 10, 30), hom_nay) == 1
    assert so_ngay_den_sinh_nhat(date(2000, 10, 28), hom_nay) == 364
    print("Đến sinh nhật 15/01:", so_ngay_den_sinh_nhat(date(1999, 1, 15), hom_nay), "ngày")
Đến sinh nhật 15/01: 78 ngày

Truyền hom_nay vào làm tham số thay vì gọi date.today() bên trong giúp hàm cho kết quả cố định, nên kiểm tra được. Đây là thói quen thiết kế bạn sẽ thấy lại ở bài pytest. try/except xử lý người sinh 29/2; bạn sẽ học kỹ ở chặng 3.

Bài 2. Package tiện ích

Tạo package tien_ich chứa tien_te.py (hàm vnd) và ngay_thang.py (bài 1). Trong main.py, import theo hai cách khác nhau và gọi cả hai hàm.
