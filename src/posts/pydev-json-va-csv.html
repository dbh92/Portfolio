File văn bản tự do khó đọc lại bằng máy. Khi lưu dữ liệu có cấu trúc, lập trình viên dùng hai định dạng phổ biến nhất: JSON cho dữ liệu lồng nhau (cấu hình, dữ liệu ứng dụng, Web API) và CSV cho dữ liệu dạng bảng (mở được bằng Excel). Python có sẵn module json và csv cho cả hai.

1. JSON: dict và list ra file

import json
from pathlib import Path

danh_ba = [
    {"ten": "Nguyễn An", "sdt": "0912345678", "nhom": ["bạn", "công ty"]},
    {"ten": "Trần Bình", "sdt": "0987654321", "nhom": [], "ghi_chu": None},
]

p = Path("danh_ba.json")
with open(p, "w", encoding="utf-8") as f:
    json.dump(danh_ba, f, ensure_ascii=False, indent=2)

with open(p, encoding="utf-8") as f:
    doc_lai = json.load(f)
print(doc_lai == danh_ba, doc_lai[1]["ghi_chu"])
for dong in p.read_text(encoding="utf-8").splitlines()[:4]:   # 4 dòng đầu của file
    print(dong)

  • json.dump(obj, f) ghi ra file, json.load(f) đọc từ file. Phiên bản có chữ s làm việc với chuỗi: json.dumps(obj), json.loads(chuoi).
  • ensure_ascii=False giữ nguyên chữ tiếng Việt; không có nó, "Nguyễn" thành "Nguyễn" (vẫn đúng nhưng khó đọc).
  • indent=2 xuống dòng, thụt lề cho người đọc được.
  • Số điện thoại lưu dạng chuỗi: lưu số thì mất số 0 đầu.

2. Kiểu không chuyển được: ngày tháng, set

import json
from datetime import date

chi_tieu = {"ngay": date(2026, 10, 29), "so_tien": 45000}
# json.dumps(chi_tieu) → TypeError: Object of type date is not JSON serializable

chuoi = json.dumps(chi_tieu, default=str)          # cách nhanh: chuyển mọi thứ lạ thành chuỗi
print(chuoi)

du_lieu = json.loads(chuoi)
du_lieu["ngay"] = date.fromisoformat(du_lieu["ngay"])   # tự chuyển ngược khi đọc
print(du_lieu)
{"ngay": "2026-10-29", "so_tien": 45000}
{'ngay': datetime.date(2026, 10, 29), 'so_tien': 45000}

Quy ước tốt: lưu ngày theo chuẩn ISO YYYY-MM-DD (đúng là thứ str(date) tạo ra), đọc lại bằng date.fromisoformat. Ở chặng 9, Pydantic sẽ tự làm việc này cho bạn.

3. CSV: dữ liệu dạng bảng

import csv

nhan_vien = [
    {"ma": "NV01", "ho_ten": "Lê Thị Hoa", "phong": "Kế toán", "luong": 15000000},
    {"ma": "NV02", "ho_ten": "Phạm Văn Đức, Jr.", "phong": "IT", "luong": 22000000},
]

with open("nhan_vien.csv", "w", encoding="utf-8-sig", newline="") as f:
    w = csv.DictWriter(f, fieldnames=["ma", "ho_ten", "phong", "luong"])
    w.writeheader()
    w.writerows(nhan_vien)

with open("nhan_vien.csv", encoding="utf-8-sig", newline="") as f:
    for dong in csv.DictReader(f):
        print(dong["ho_ten"], "|", int(dong["luong"]) // 1_000_000, "triệu")
Lê Thị Hoa | 15 triệu
Phạm Văn Đức, Jr. | 22 triệu

Ba chi tiết quyết định file CSV có dùng được hay không:

  • newline="": bắt buộc khi mở file cho module csv, nếu không trên Windows sẽ xuất hiện dòng trống xen kẽ.
  • encoding="utf-8-sig": ghi thêm dấu BOM ở đầu file để Excel nhận đúng tiếng Việt khi mở bằng cách nhấp đúp. Ghi utf-8 thường thì Excel thường hiển thị "LÃª Thá»‹". Khi đọc, utf-8-sig tự bỏ BOM nếu có.
  • Đừng tự nối chuỗi bằng ",".join(...): tên "Phạm Văn Đức, Jr." có dấu phẩy sẽ làm lệch cột. Module csv tự bọc giá trị như vậy trong dấu nháy kép.
CSV chỉ có chuỗiMọi giá trị đọc từ CSV đều là str, kể cả "22000000". Nhớ ép kiểu trước khi tính toán. Đây cũng là lý do ở chặng 8 bạn sẽ dùng pandas, công cụ tự đoán kiểu cột.

4. Excel ở Việt Nam và dấu chấm phẩy

Excel trên máy cài định dạng vùng Việt Nam (dấu phẩy thập phân) thường dùng dấu chấm phẩy làm dấu phân cách khi xuất CSV. Đọc file đó bằng csv.DictReader(f, delimiter=";"). Nếu không chắc, csv.Sniffer có thể đoán:

import csv

mau = "ma;ten;gia\nSP1;Bút bi;5000\n"
kieu = csv.Sniffer().sniff(mau)
print(repr(kieu.delimiter))
';'

5. Chọn JSON hay CSV?

Tình huốngChọn
Dữ liệu dạng bảng phẳng, người dùng mở bằng ExcelCSV
Dữ liệu lồng nhau (list trong dict), cấu hình ứng dụngJSON
Trao đổi với Web APIJSON
Hàng triệu dòng, truy vấn, cập nhật thường xuyênCơ sở dữ liệu (chặng 8)

Tóm tắt

  • json.dump/load với file, dumps/loads với chuỗi; ensure_ascii=False, indent=2.
  • Ngày lưu dạng ISO, đọc lại bằng date.fromisoformat.
  • CSV: DictReader, DictWriter, newline="", utf-8-sig cho Excel.
  • Giá trị CSV luôn là chuỗi; Excel Việt Nam có thể dùng ;.

Bài tập

Bài 1. Danh bạ JSON

Viết hàm luu(danh_ba, p), nap(p) (file chưa có thì trả list rỗng) và tim(danh_ba, tu_khoa) tìm theo tên, không phân biệt hoa thường.

Xem đáp án 
import json
from pathlib import Path


def luu(danh_ba: list[dict], p: Path) -> None:
    p.write_text(json.dumps(danh_ba, ensure_ascii=False, indent=2), encoding="utf-8")


def nap(p: Path) -> list[dict]:
    if not p.exists():
        return []
    return json.loads(p.read_text(encoding="utf-8"))


def tim(danh_ba: list[dict], tu_khoa: str) -> list[dict]:
    k = tu_khoa.casefold()
    return [ng for ng in danh_ba if k in ng["ten"].casefold()]


p = Path("danh_ba.json")
db = nap(p)
db += [{"ten": "Nguyễn An", "sdt": "0912345678"}, {"ten": "An Khang", "sdt": "0909000111"},
       {"ten": "Trần Bình", "sdt": "0987654321"}]
luu(db, p)
print([ng["ten"] for ng in tim(nap(p), "an")])
['Nguyễn An', 'An Khang']

Bài 2. Thêm cột xếp loại

Đọc bang_diem.csv (cột ho_ten, diem), thêm cột xep_loai (Giỏi ≥ 8, Khá ≥ 6,5, Trung bình ≥ 5, còn lại Yếu), ghi ra bang_diem_xep_loai.csv mở được bằng Excel.

Xem đáp án 
import csv
from pathlib import Path

Path("bang_diem.csv").write_text("ho_ten,diem\nAn,8.5\nBình,6.5\nChi,4.75\nDũng,5\n", encoding="utf-8")


def xep_loai(diem: float) -> str:
    if diem >= 8:
        return "Giỏi"
    if diem >= 6.5:
        return "Khá"
    if diem >= 5:
        return "Trung bình"
    return "Yếu"


with open("bang_diem.csv", encoding="utf-8-sig", newline="") as f_vao, \
     open("bang_diem_xep_loai.csv", "w", encoding="utf-8-sig", newline="") as f_ra:
    doc = csv.DictReader(f_vao)
    ghi = csv.DictWriter(f_ra, fieldnames=doc.fieldnames + ["xep_loai"])
    ghi.writeheader()
    for dong in doc:
        dong["xep_loai"] = xep_loai(float(dong["diem"]))
        ghi.writerow(dong)

print(Path("bang_diem_xep_loai.csv").read_text(encoding="utf-8-sig"))

Bình,6.5,Khá
Chi,4.75,Yếu

Mở hai file trong cùng một with và xử lý từng dòng: dù file có hàng triệu dòng, chương trình vẫn chỉ giữ một dòng trong bộ nhớ.

Nguồn tham khảo: json: JSON encoder and decoder; csv: CSV File Reading and Writing; codecs: utf-8-sig.
