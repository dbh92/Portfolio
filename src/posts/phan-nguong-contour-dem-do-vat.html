Rất nhiều bài toán Machine Vision trong nhà máy, như đếm sản phẩm, kiểm tra có/không có linh kiện, đo diện tích, được giải quyết bằng một chuỗi xử lý cổ điển: làm mờ → phân ngưỡng → hình thái học → tìm contour → đo đặc trưng. Không cần AI, chạy cực nhanh và dễ giải thích với khách hàng.

Bước 1: làm mờ để giảm nhiễu

import cv2
import numpy as np

img = cv2.imread("khay-oc-vit.png")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)

Kernel càng lớn thì càng mịn nhưng biên vật càng nhòe. Với nhiễu dạng "muối tiêu", dùng cv2.medianBlur(gray, 5) hiệu quả hơn.

Bước 2: phân ngưỡng

Phân ngưỡng biến ảnh xám thành ảnh nhị phân: vật = trắng (255), nền = đen (0).

# Ngưỡng cố định: dùng khi ánh sáng rất ổn định
_, th = cv2.threshold(blur, 120, 255, cv2.THRESH_BINARY)

# Otsu: tự tìm ngưỡng tối ưu khi histogram có 2 đỉnh (vật và nền)
t, th = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print("Ngưỡng Otsu:", t)

# Thích nghi: khi ánh sáng không đều trên ảnh
th_ad = cv2.adaptiveThreshold(blur, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                              cv2.THRESH_BINARY, 31, 5)

Nếu vật tối hơn nền, dùng cv2.THRESH_BINARY_INV để vật luôn là màu trắng. Thực tế, ánh sáng tốt quan trọng hơn thuật toán phân ngưỡng giỏi: một tấm đèn nền (backlight) biến bài toán khó thành dễ.

Bước 3: hình thái học (morphology)

kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
clean = cv2.morphologyEx(th, cv2.MORPH_OPEN, kernel)     # xóa đốm nhiễu nhỏ
clean = cv2.morphologyEx(clean, cv2.MORPH_CLOSE, kernel) # lấp lỗ nhỏ trong vật

Bước 4: tìm contour và lọc theo diện tích

contours, _ = cv2.findContours(clean, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

objects = []
for c in contours:
    area = cv2.contourArea(c)
    if area < 200:                  # bỏ nhiễu
        continue
    x, y, w, h = cv2.boundingRect(c)
    M = cv2.moments(c)
    cx, cy = int(M["m10"] / M["m00"]), int(M["m01"] / M["m00"])
    objects.append((area, cx, cy))
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)
    cv2.circle(img, (cx, cy), 3, (0, 0, 255), -1)

print("Số vật:", len(objects))

RETR_EXTERNAL chỉ lấy đường bao ngoài cùng, phù hợp để đếm. Nếu cần lỗ bên trong (ví dụ kiểm tra vòng đệm có lỗ hay không) thì dùng RETR_CCOMP hoặc RETR_TREE và đọc mảng hierarchy.

Bước 5: đặc trưng để phân loại OK/NG

Đặc trưngCách tínhDùng để
Diện tíchcv2.contourArea(c)Phát hiện vật thiếu, vỡ, dính chùm
Chu vicv2.arcLength(c, True)Phát hiện mép răng cưa, ba via
Độ tròn4π·A / P²Phân biệt vật tròn và méo
Hình chữ nhật xoaycv2.minAreaRect(c)Đo dài/rộng, góc xoay
Độ đặc (solidity)A / diện tích bao lồiPhát hiện vết khuyết, mẻ
import math
for c in contours:
    A = cv2.contourArea(c)
    P = cv2.arcLength(c, True)
    if A < 200 or P == 0:
        continue
    roundness = 4 * math.pi * A / (P * P)
    hull_area = cv2.contourArea(cv2.convexHull(c))
    solidity = A / hull_area if hull_area else 0
    status = "OK" if 0.80 < roundness and solidity > 0.95 else "NG"

Khi hai vật dính nhau

Hai vật chạm nhau sẽ thành một contour lớn, làm sai số đếm. Cách xử lý phổ biến: chia theo diện tích chuẩn (round(area / area_1_vat)) hoặc tách bằng distance transform + watershed. Tốt nhất vẫn là thiết kế cơ khí (rung, tách hàng) để vật không chồng lên nhau.
