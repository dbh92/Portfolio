Huấn luyện mô hình bằng Python nhưng phần mềm trạm kiểm tra viết bằng C#? Cầu nối phổ biến nhất là ONNX: xuất mô hình sang định dạng chuẩn, rồi chạy bằng ONNX Runtime ngay trong ứng dụng .NET, không cần cài Python trên máy công nghiệp.

Bước 1: xuất mô hình sang ONNX (Python)

from ultralytics import YOLO
YOLO("best.pt").export(format="onnx", imgsz=640)     # tạo best.onnx

# Với mô hình PyTorch tự viết:
# torch.onnx.export(model, torch.randn(1, 3, 224, 224), "model.onnx",
#                   input_names=["input"], output_names=["output"])

Bước 2: cài ONNX Runtime cho .NET

dotnet add package Microsoft.ML.OnnxRuntime          # CPU
# GPU NVIDIA: Microsoft.ML.OnnxRuntime.Gpu ; Windows mọi GPU: Microsoft.ML.OnnxRuntime.DirectML

Bước 3: xem đầu vào/đầu ra của mô hình

using Microsoft.ML.OnnxRuntime;
using Microsoft.ML.OnnxRuntime.Tensors;

using var session = new InferenceSession("best.onnx");
foreach (var (name, meta) in session.InputMetadata)
    Console.WriteLine($"Input  {name}: [{string.Join(",", meta.Dimensions)}]");
foreach (var (name, meta) in session.OutputMetadata)
    Console.WriteLine($"Output {name}: [{string.Join(",", meta.Dimensions)}]");

Luôn in ra kích thước thực tế trước khi viết code giải mã: mỗi họ mô hình (và mỗi phiên bản YOLO) có định dạng đầu ra khác nhau. Ví dụ YOLOv8/YOLO11 xuất mảng dạng [1, 4 + số lớp, số anchor] và cần NMS; YOLO26 thiết kế end-to-end nên đầu ra đã là các khung cuối cùng.

Bước 4: tiền xử lý ảnh đúng như lúc huấn luyện

using OpenCvSharp;

static DenseTensor<float> ToTensor(Mat bgr, int size)
{
    using var resized = new Mat();
    Cv2.Resize(bgr, resized, new Size(size, size));      // đơn giản; chuẩn hơn là letterbox giữ tỷ lệ
    using var rgb = new Mat();
    Cv2.CvtColor(resized, rgb, ColorConversionCodes.BGR2RGB);

    var tensor = new DenseTensor<float>(new[] { 1, 3, size, size });
    var idx = rgb.GetGenericIndexer<Vec3b>();
    for (int y = 0; y < size; y++)
        for (int x = 0; x < size; x++)
        {
            var px = idx[y, x];
            tensor[0, 0, y, x] = px.Item0 / 255f;   // R
            tensor[0, 1, y, x] = px.Item1 / 255f;   // G
            tensor[0, 2, y, x] = px.Item2 / 255f;   // B
        }
    return tensor;
}

Sai một chi tiết tiền xử lý (thứ tự kênh RGB/BGR, chia 255, chuẩn hóa mean/std, letterbox) là nguyên nhân số 1 khiến mô hình chạy trong C# cho kết quả khác Python. Hãy so sánh đầu ra của cùng một ảnh trên cả hai phía.

Bước 5: chạy suy luận

using var img = Cv2.ImRead("test.png");
var input = ToTensor(img, 640);
string inputName = session.InputMetadata.Keys.First();

using var results = session.Run(new List<NamedOnnxValue>
{
    NamedOnnxValue.CreateFromTensor(inputName, input)
});
var output = results.First().AsTensor<float>();
Console.WriteLine($"Output shape: [{string.Join(",", output.Dimensions.ToArray())}]");
// Giải mã theo định dạng đầu ra của mô hình: khung, lớp, điểm tin cậy...

Hiệu năng

  • Tạo InferenceSession một lần khi khởi động, dùng lại cho mọi ảnh.
  • Chạy "khởi động nóng" vài ảnh trước khi đo tốc độ: lần chạy đầu luôn chậm.
  • Truy cập DenseTensor theo chỉ số nhiều chiều khá chậm; với đầu ra lớn, làm việc trên mảng phẳng sẽ nhanh hơn.
  • Với GPU NVIDIA, cân nhắc TensorRT; với CPU Intel, cân nhắc OpenVINO Execution Provider.

Đây là kỹ năng cốt lõi của chặng Deployment trong lộ trình Vision Engineer.
