Python là ngôn ngữ nền tảng cho AI và xử lý ảnh. Có nhiều sách Python chất lượng cao được tác giả cho phép đọc miễn phí trực tuyến. Dưới đây là các lựa chọn tốt nhất, sắp xếp theo trình độ.

Cho người mới bắt đầu

Automate the Boring Stuff with Python (Al Sweigart)

Học Python qua việc tự động hóa công việc thực tế: xử lý file, thư mục, Excel, PDF, email, trình duyệt. Rất hợp với kỹ sư muốn dùng Python ngay cho công việc hằng ngày. Đọc miễn phí tại automatetheboringstuff.com.

Think Python (Allen B. Downey)

Giới thiệu tư duy lập trình bài bản: biến, hàm, vòng lặp, cấu trúc dữ liệu, lập trình hướng đối tượng, mỗi chương có bài tập. Phiên bản mới có thể đọc trực tuyến miễn phí trên trang của tác giả (Green Tea Press).

Cho phân tích dữ liệu và khoa học

Python Data Science Handbook (Jake VanderPlas)

Hướng dẫn NumPy, Pandas, Matplotlib và scikit-learn: đúng bộ công cụ bạn cần trước khi học Machine Learning. Bản đầy đủ dạng notebook được tác giả công bố miễn phí trên GitHub và trang jakevdp.github.io/PythonDataScienceHandbook.

Tài liệu chính thức

  • The Python Tutorial trên docs.python.org: ngắn gọn, chính xác, luôn cập nhật theo phiên bản Python.
  • NumPy: the absolute basics for beginners trong tài liệu chính thức của NumPy.

Lộ trình đọc gợi ý

  1. Tuần 1–4: Automate the Boring Stuff (các chương cơ bản) hoặc Think Python, gõ lại mọi ví dụ.
  2. Tuần 5–6: The Python Tutorial để củng cố các khái niệm còn mơ hồ.
  3. Tuần 7–10: Python Data Science Handbook phần NumPy và Matplotlib, rồi sang NumPy cho xử lý ảnh.

Học hiệu quả với sách lập trình

  • Gõ lại code, không copy-paste: bàn tay học cùng với đầu óc.
  • Sửa ví dụ: đổi tham số, thêm tính năng, cố ý làm lỗi để xem thông báo.
  • Áp dụng ngay: tìm một việc lặp đi lặp lại ở nơi làm việc và tự động hóa nó.

Lưu ý: chỉ dùng phiên bản do tác giả hoặc nhà xuất bản công bố. Nếu sách giúp ích cho bạn, hãy cân nhắc mua bản in để ủng hộ tác giả.
