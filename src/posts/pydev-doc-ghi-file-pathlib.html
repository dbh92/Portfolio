Chương trình ở chặng 2 mất sạch dữ liệu khi tắt. Muốn lưu lại, đọc dữ liệu người khác gửi, hay dọn một thư mục hàng nghìn file, bạn cần làm việc với file và đường dẫn. Bài này dạy cách đọc ghi file văn bản an toàn với tiếng Việt và dùng pathlib, cách xử lý đường dẫn hiện đại chạy giống nhau trên Windows, macOS và Linux.

1. Ghi và đọc file với with

with open("ghi_chu.txt", "w", encoding="utf-8") as f:
    f.write("Dòng 1: Học Python\n")
    f.write("Dòng 2: Đọc ghi file\n")

with open("ghi_chu.txt", "a", encoding="utf-8") as f:   # "a": ghi nối vào cuối
    print("Dòng 3: thêm bằng print", file=f)

with open("ghi_chu.txt", encoding="utf-8") as f:        # mặc định "r": đọc
    noi_dung = f.read()
print(noi_dung)
Dòng 1: Học Python
Dòng 2: Đọc ghi file
Dòng 3: thêm bằng print
  • with tự đóng file khi ra khỏi khối, kể cả khi có lỗi. Không dùng with mà quên close() có thể làm mất dữ liệu chưa ghi.
  • Chế độ: "r" đọc, "w" ghi mới (xóa nội dung cũ), "a" ghi nối, "x" chỉ tạo mới (báo lỗi nếu file đã có). Thêm "b" cho file nhị phân như ảnh: "rb", "wb".
  • write() không tự xuống dòng, phải thêm "\n"; print(..., file=f) thì có.

2. Luôn ghi rõ encoding="utf-8"

Trước Python 3.15, nếu không ghi encoding, Python dùng bảng mã mặc định của hệ điều hành. Trên nhiều máy Windows đó là cp1252, nên file tiếng Việt viết trên Linux đọc trên Windows bị lỗi UnicodeDecodeError hoặc ra chữ lạ. Từ Python 3.15, UTF-8 đã thành mặc định trên mọi hệ điều hành, nhưng tài liệu chính thức vẫn khuyên ghi rõ encoding="utf-8" để code chạy đúng trên mọi phiên bản. Hãy coi nó là một phần bắt buộc của open().

3. Đọc từng dòng

with open("diem.txt", "w", encoding="utf-8") as f:
    f.write("An,8.5\nBình,7\n\nChi,9.25\n")

with open("diem.txt", encoding="utf-8") as f:
    for so_dong, dong in enumerate(f, start=1):   # duyệt file theo dòng
        dong = dong.strip()                        # bỏ "\n" cuối dòng
        if not dong:
            continue
        ten, diem = dong.split(",")
        print(so_dong, ten, float(diem))

with open("diem.txt", encoding="utf-8") as f:
    cac_dong = f.read().splitlines()               # list các dòng, không kèm "\n"
print(cac_dong)
1 An 8.5
2 Bình 7.0
4 Chi 9.25
['An,8.5', 'Bình,7', '', 'Chi,9.25']

Duyệt thẳng đối tượng file bằng for đọc từng dòng một, nên xử lý được file vài GB mà không tốn bộ nhớ. read() nạp cả file vào bộ nhớ, chỉ dùng cho file nhỏ.

4. pathlib: đường dẫn là đối tượng

from pathlib import Path

goc = Path("du_an")
file_cfg = goc / "cau_hinh" / "app.json"     # nối đường dẫn bằng dấu /
print(file_cfg)                               # tự dùng \ trên Windows, / trên Linux
print(file_cfg.name, file_cfg.stem, file_cfg.suffix)
print(file_cfg.parent, file_cfg.with_suffix(".bak").name)

file_cfg.parent.mkdir(parents=True, exist_ok=True)   # tạo thư mục, kể cả thư mục cha
file_cfg.write_text('{"debug": true}', encoding="utf-8")
print(file_cfg.exists(), file_cfg.is_file(), file_cfg.parent.is_dir())
print(file_cfg.read_text(encoding="utf-8"))
print(file_cfg.stat().st_size, "byte")
du_an/cau_hinh/app.json
app.json app .json
du_an/cau_hinh app.bak
True True True
{"debug": true}
15 byte

(Trên Windows, dòng đầu in du_an\cau_hinh\app.json.) Các thuộc tính hay dùng: name (tên file), stem (tên không đuôi), suffix (đuôi), parent (thư mục chứa). write_text, read_text là cách ngắn gọn cho file nhỏ.

Thư mục của chính scriptĐường dẫn tương đối như Path("du_lieu.txt") tính từ thư mục bạn đang đứng khi chạy lệnh, không phải thư mục chứa script. Muốn luôn tìm file nằm cạnh script, dùng Path(__file__).parent / "du_lieu.txt". Điều này rất quan trọng khi script chạy theo lịch (chặng 7).

5. Duyệt thư mục, tìm file theo mẫu

from pathlib import Path

thu_muc = Path("kho")
for ten in ["a.txt", "b.csv", "nhom/c.txt", "nhom/sau/d.TXT", "nhom/e.jpg"]:
    p = thu_muc / ten
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text("x" * len(ten), encoding="utf-8")

print(sorted(p.name for p in thu_muc.iterdir()))          # chỉ cấp đầu
print(sorted(p.name for p in thu_muc.glob("*.txt")))      # theo mẫu, cấp đầu
print(sorted(p.name for p in thu_muc.rglob("*.txt")))     # mọi cấp con
txt = [p for p in thu_muc.rglob("*") if p.is_file() and p.suffix.lower() == ".txt"]
print(sorted(p.relative_to(thu_muc).as_posix() for p in txt))
['a.txt', 'b.csv', 'nhom']
['a.txt']
['a.txt', 'c.txt']
['a.txt', 'nhom/c.txt', 'nhom/sau/d.TXT']

glob("*.txt") tìm ở cấp hiện tại, rglob tìm đệ quy mọi cấp con. Mẫu phân biệt hoa thường tùy hệ điều hành: kết quả trên là của Linux; trên Windows, dòng thứ ba có thêm 'd.TXT' vì hệ thống file Windows không phân biệt hoa thường. Muốn kết quả giống nhau mọi nơi, so sánh p.suffix.lower() như dòng cuối. Thứ tự file trả về không cố định, nên dùng sorted() khi cần ổn định.

6. Đổi tên, di chuyển, xóa

import shutil
from pathlib import Path

p = Path("tam.txt")
p.write_text("tạm", encoding="utf-8")
moi = p.rename("tam_cu.txt")          # đổi tên; trả về Path mới
Path("luu_tru").mkdir(exist_ok=True)
shutil.move(moi, "luu_tru/tam_cu.txt")    # di chuyển (kể cả khác ổ đĩa)
shutil.copy("luu_tru/tam_cu.txt", "ban_sao.txt")
Path("ban_sao.txt").unlink()          # xóa file
shutil.rmtree("luu_tru")              # xóa cả thư mục và mọi thứ bên trong
print(Path("luu_tru").exists())
False
Xóa là mất luônunlink() và shutil.rmtree() không đưa file vào thùng rác. Script xóa hoặc di chuyển hàng loạt nên có chế độ "chạy thử" chỉ in ra sẽ làm gì; bạn sẽ làm điều này ở bài thực hành cuối chặng.

Tóm tắt

  • with open(p, mode, encoding="utf-8") as f; "w" xóa nội dung cũ.
  • Duyệt file theo dòng bằng for dong in f; nhớ strip().
  • Path: nối bằng /, name, stem, suffix, parent, mkdir(parents=True, exist_ok=True).
  • glob, rglob, iterdir để duyệt; shutil để chép, di chuyển, xóa thư mục.

Bài tập

Bài 1. Đếm dòng, từ, ký tự

Viết hàm thong_ke_file(duong_dan) trả về tuple (số dòng, số từ, số ký tự) của một file văn bản UTF-8.

Xem đáp án 
from pathlib import Path


def thong_ke_file(duong_dan: str | Path) -> tuple[int, int, int]:
    so_dong = so_tu = so_ky_tu = 0
    with open(duong_dan, encoding="utf-8") as f:
        for dong in f:
            so_dong += 1
            so_tu += len(dong.split())
            so_ky_tu += len(dong.rstrip("\n"))
    return so_dong, so_tu, so_ky_tu


Path("bai.txt").write_text("Xin chào Việt Nam\nHọc Python mỗi ngày\n", encoding="utf-8")
print(thong_ke_file("bai.txt"))
(2, 8, 36)

str | Path trong type hint nghĩa là "chuỗi hoặc Path"; open() nhận được cả hai.

Bài 2. Mười file lớn nhất

Liệt kê 10 file lớn nhất trong một thư mục và mọi thư mục con, in đường dẫn tương đối và kích thước KB.

Xem đáp án 
from pathlib import Path


def file_lon_nhat(thu_muc: Path, n: int = 10) -> list[tuple[Path, int]]:
    cac_file = [(p, p.stat().st_size) for p in thu_muc.rglob("*") if p.is_file()]
    return sorted(cac_file, key=lambda cap: cap[1], reverse=True)[:n]


goc = Path("thu_nghiem")
for i, kb in enumerate([3, 120, 45, 7]):
    f = goc / f"nhom{i % 2}" / f"file{i}.bin"
    f.parent.mkdir(parents=True, exist_ok=True)
    f.write_bytes(b"\0" * kb * 1024)

for p, kich_thuoc in file_lon_nhat(goc, 3):
    print(f"{kich_thuoc / 1024:8.1f} KB  {p.relative_to(goc).as_posix()}")
   120.0 KB  nhom1/file1.bin
    45.0 KB  nhom0/file2.bin
     7.0 KB  nhom1/file3.bin

Thay goc bằng Path.home() / "Downloads" để chạy trên thư mục thật của bạn.
