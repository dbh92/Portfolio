Mã 2D như QR Code và DataMatrix là "chứng minh thư" của sản phẩm: số seri, lô, ngày sản xuất. Đọc mã tự động trên dây chuyền là nền tảng của truy xuất nguồn gốc. Dự án này đọc mã trên bao bì bằng Python, kèm kiểm tra chất lượng in cơ bản và mã nguồn đầy đủ.

Cài đặt

pip install opencv-python pylibdmtx

pylibdmtx cần thư viện libdmtx của hệ điều hành (trên Ubuntu: sudo apt install libdmtx0b; trên Windows, gói pip thường kèm sẵn DLL). QR Code đọc được bằng OpenCV có sẵn.

Mã nguồn

import cv2
import numpy as np
from pylibdmtx.pylibdmtx import decode as dm_decode

qr = cv2.QRCodeDetector()

def preprocess(gray):
    gray = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8)).apply(gray)
    return cv2.GaussianBlur(gray, (3, 3), 0)

def read_codes(bgr):
    gray = preprocess(cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY))
    found = []

    text, pts, _ = qr.detectAndDecode(gray)
    if text:
        found.append(("QR", text, pts.reshape(-1, 2).astype(int)))

    for r in dm_decode(gray, timeout=200, max_count=1):     # timeout: mili giây
        x, y, w, h = r.rect.left, r.rect.top, r.rect.width, r.rect.height
        # libdmtx dùng gốc tọa độ ở dưới-trái; đổi sang gốc trên-trái của ảnh
        y = gray.shape[0] - y - h
        found.append(("DataMatrix", r.data.decode("utf-8", "replace"),
                      [(x, y), (x + w, y), (x + w, y + h), (x, y + h)]))
    return found

cap = cv2.VideoCapture(0)
seen = set()
while True:
    ok, frame = cap.read()
    if not ok:
        break
    for kind, text, box in read_codes(frame):
        cv2.polylines(frame, [np.array(box, dtype=np.int32).reshape(-1, 1, 2)], True, (0, 255, 0), 2)
        x0, y0 = box[0]
        cv2.putText(frame, f"{kind}: {text}", (int(x0), int(y0) - 8),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)
        if text not in seen:
            seen.add(text)
            print(kind, text)
    cv2.imshow("Doc ma", frame)
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break
cap.release()
cv2.destroyAllWindows()

Kiểm tra dữ liệu đọc được

Đọc được mã chưa đủ; cần kiểm tra nội dung hợp lệ trước khi chấp nhận:

import re

PATTERN = re.compile(r"^SN\d{10}$")          # ví dụ định dạng số seri

def validate(text, expected_lot=None):
    if not PATTERN.match(text):
        return False, "sai định dạng"
    if expected_lot and expected_lot not in text:
        return False, "không khớp lô sản xuất"
    return True, "OK"

Đưa vào dây chuyền

  • Trigger bằng cảm biến quang, chụp đúng lúc mã nằm giữa khung hình.
  • Phát hiện trùng lặp: cùng một mã xuất hiện hai lần trên dây chuyền là dấu hiệu lỗi in hoặc lỗi quy trình.
  • Chất lượng in: các tiêu chuẩn ISO/IEC (ví dụ ISO/IEC 15415 cho mã 2D in, ISO/IEC TR 29158 cho mã khắc trực tiếp) đánh giá độ tương phản, độ đều, độ lệch. Thiết bị kiểm định chuyên dụng cho kết quả chính thức; vision tự viết phù hợp để cảnh báo sớm.
  • Mã khắc trên kim loại cần chiếu sáng đồng trục hoặc góc thấp.
  • Gửi số seri và kết quả lên MES để truy xuất (xem MES và truy xuất nguồn gốc).
