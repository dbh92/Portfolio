Mọi mạng nơ-ron hiện đại, từ YOLO đến các mô hình ngôn ngữ lớn, đều học theo cùng một nguyên lý: tối thiểu hóa hàm mất mát bằng gradient descent. Cách tốt nhất để hiểu nguyên lý này là tự cài đặt nó cho bài toán đơn giản nhất: hồi quy tuyến tính, chỉ với NumPy.

Bài toán

Dự đoán nhiệt độ lò y từ công suất cấp x, giả định quan hệ tuyến tính y ≈ w·x + b. Ta cần tìm w và b từ dữ liệu.

import numpy as np

rng = np.random.default_rng(0)
x = rng.uniform(10, 100, size=200)          # công suất (%)
y = 3.2 * x + 25 + rng.normal(0, 8, 200)    # nhiệt độ thật có nhiễu

Hàm mất mát

Đo độ sai bằng trung bình bình phương sai số (MSE):

def mse(w, b):
    return np.mean((w * x + b - y) ** 2)

Gradient: hướng làm loss tăng nhanh nhất

Lấy đạo hàm của MSE theo w và b:

dL/dw = 2 · mean((w·x + b − y) · x)
dL/db = 2 · mean(w·x + b − y)

Gradient descent đi ngược hướng gradient từng bước nhỏ:

Cài đặt

x_n = (x - x.mean()) / x.std()      # chuẩn hóa giúp hội tụ nhanh và ổn định

w, b, lr = 0.0, 0.0, 0.1
for step in range(200):
    err = w * x_n + b - y
    dw = 2 * np.mean(err * x_n)
    db = 2 * np.mean(err)
    w -= lr * dw
    b -= lr * db
    if step % 50 == 0:
        print(step, round(np.mean(err ** 2), 2))

# đổi tham số về thang đo gốc của x
w_goc = w / x.std()
b_goc = b - w * x.mean() / x.std()
print(f"y ≈ {w_goc:.2f}·x + {b_goc:.2f}")    # gần với 3.2·x + 25

Learning rate quan trọng thế nào?

  • Quá nhỏ: hội tụ rất chậm.
  • Quá lớn: loss dao động hoặc tăng vọt (phân kỳ).
  • Thử với lr = 0.001, 0.1, 1.1 và quan sát loss để có cảm nhận trực quan.
