Bài thực hành đầu tiên ghép mọi thứ của chặng 1 vào hai chương trình hoàn chỉnh: trò chơi đoán số và máy tính tiền điện bậc thang. Mục tiêu không chỉ là chạy được, mà là tập quy trình người đi làm vẫn dùng: hiểu đề → chia bước → viết từng bước → chạy thử với dữ liệu biết trước kết quả.

1. Chia bài toán trước khi viết code

Đừng mở VS Code ngay. Viết ra giấy (hoặc comment) các bước bằng tiếng Việt. Với trò đoán số:

  1. Máy chọn ngẫu nhiên một số từ 1 đến 100.
  2. Lặp tối đa 7 lượt: hỏi người chơi một số.
  3. Nếu nhập không phải số hoặc ngoài 1–100: báo lỗi, không tính lượt.
  4. So sánh: lớn hơn, nhỏ hơn, hoặc đúng thì chúc mừng và dừng.
  5. Hết 7 lượt mà chưa đúng: thông báo đáp án.

Mỗi bước gần như là một vài dòng code. Vì sao 7 lượt? Mỗi lần đoán ở giữa khoảng còn lại sẽ loại một nửa khả năng: 100 → 50 → 25 → 13 → 7 → 4 → 2 → 1. Người chơi khéo luôn thắng trong 7 lượt; đây chính là ý tưởng của tìm kiếm nhị phân.

2. Trò chơi đoán số

import random

SO_LUOT = 7
bi_mat = random.randint(1, 100)       # số nguyên ngẫu nhiên, gồm cả 1 và 100
print(f"Tôi đã chọn một số từ 1 đến 100. Bạn có {SO_LUOT} lượt.")

luot = 0
while luot < SO_LUOT:
    nhap = input(f"Lượt {luot + 1}: ").strip()
    if not nhap.isdigit():
        print("  Hãy nhập một số nguyên dương.")
        continue                       # không tăng lượt
    doan = int(nhap)
    if not 1 <= doan <= 100:
        print("  Số phải trong khoảng 1–100.")
        continue
    luot += 1
    if doan < bi_mat:
        print("  Lớn hơn nữa.")
    elif doan > bi_mat:
        print("  Nhỏ hơn nữa.")
    else:
        print(f"  Chính xác! Bạn đoán đúng sau {luot} lượt.")
        break
else:
    print(f"Hết lượt. Số bí mật là {bi_mat}.")

Các điểm đáng chú ý:

  • isdigit() kiểm tra chuỗi chỉ gồm chữ số trước khi gọi int(), tránh lỗi ValueError. Ở chặng 3 bạn sẽ dùng try/except cho việc này.
  • continue khi nhập sai nằm trước luot += 1, nên nhập sai không mất lượt.
  • while ... else: khối else chỉ chạy khi hết lượt mà không break, tức là người chơi thua.
  • SO_LUOT viết hoa vì là hằng số cấu hình; muốn đổi luật chỉ sửa một chỗ.
Mẹo kiểm thử với số ngẫu nhiênThêm random.seed(1) ngay sau import random thì mỗi lần chạy máy chọn cùng một số. Nhờ vậy bạn kiểm tra được mọi nhánh. Nhớ xóa dòng đó khi chơi thật.

3. Tính tiền điện bậc thang

Giá điện sinh hoạt ở Việt Nam tính lũy tiến theo bậc: số kWh ở bậc nào tính theo giá bậc đó. Bài dùng biểu giá theo Quyết định 1279/QĐ-BCT (hiệu lực từ 10/05/2025), giá chưa gồm thuế GTGT:

BậcMức sử dụngGiá (đ/kWh)
10–50 kWh1.984
251–100 kWh2.050
3101–200 kWh2.380
4201–300 kWh2.998
5301–400 kWh3.350
6Từ 401 kWh3.460

Giá điện có thể được điều chỉnh; khi dùng thật, hãy kiểm tra biểu giá hiện hành trên trang của EVN. Cách thiết kế dưới đây giúp đổi giá chỉ bằng cách sửa bảng, không sửa logic.

Trước khi code, tính tay một ví dụ để có kết quả đối chiếu. Với 150 kWh: 50 × 1.984 + 50 × 2.050 + 50 × 2.380 = 99.200 + 102.500 + 119.000 = 320.700 đ.

# (mức trần của bậc, giá); None nghĩa là không giới hạn
BAC_GIA = [(50, 1984), (100, 2050), (200, 2380), (300, 2998), (400, 3350), (None, 3460)]

so_kwh = 150
con_lai = so_kwh
muc_duoi = 0
tong = 0
for muc_tran, gia in BAC_GIA:
    if con_lai <= 0:
        break
    do_rong = con_lai if muc_tran is None else muc_tran - muc_duoi
    kwh_bac = min(con_lai, do_rong)
    tien = kwh_bac * gia
    print(f"{kwh_bac:4} kWh x {gia:,} = {tien:>10,} đ")
    tong += tien
    con_lai -= kwh_bac
    if muc_tran is not None:
        muc_duoi = muc_tran
print(f"Tổng {so_kwh} kWh: {tong:,} đ (chưa thuế)")
  50 kWh x 1,984 =     99,200 đ
  50 kWh x 2,050 =    102,500 đ
  50 kWh x 2,380 =    119,000 đ
Tổng 150 kWh: 320,700 đ (chưa thuế)

Kết quả khớp với số tính tay. Ý tưởng chính: mỗi bậc "ăn" tối đa do_rong kWh (độ rộng của bậc), phần còn lại chuyển xuống bậc sau. Bậc cuối có muc_tran = None nên ăn hết phần còn lại.

Kiểm tra ranh giớiLỗi bậc thang hay nằm ở ranh giới: 50, 51, 100, 101 kWh. Luôn thử các giá trị đó. Với 50 kWh kết quả phải là 99.200 đ; với 51 kWh phải là 99.200 + 2.050 = 101.250 đ. Ở chặng 6, bạn sẽ biến các phép thử này thành test tự động bằng pytest.

4. Tổng kết quy trình

  • Viết các bước bằng lời trước khi code.
  • Tính tay ít nhất một ví dụ để có đáp án đối chiếu.
  • Đưa các con số dễ thay đổi (số lượt, bảng giá) lên đầu file thành hằng số.
  • Thử dữ liệu sai (chữ thay số, số âm) và giá trị ranh giới.

Bài tập

Bài 1. Hỏi chơi lại

Bọc trò chơi trong một vòng lặp ngoài: hết ván thì hỏi "Chơi lại? (c/k)", trả lời c thì chơi ván mới với số bí mật mới.

Xem đáp án 
import random

SO_LUOT = 7
while True:
    bi_mat = random.randint(1, 100)
    luot = 0
    print(f"\nSố mới từ 1 đến 100, bạn có {SO_LUOT} lượt.")
    while luot < SO_LUOT:
        nhap = input(f"Lượt {luot + 1}: ").strip()
        if not nhap.isdigit() or not 1 <= int(nhap) <= 100:
            print("  Nhập số nguyên từ 1 đến 100.")
            continue
        luot += 1
        doan = int(nhap)
        if doan == bi_mat:
            print(f"  Chính xác sau {luot} lượt!")
            break
        print("  Lớn hơn nữa." if doan < bi_mat else "  Nhỏ hơn nữa.")
    else:
        print(f"Hết lượt. Số bí mật là {bi_mat}.")
    if input("Chơi lại? (c/k): ").strip().lower() != "c":
        print("Hẹn gặp lại!")
        break

not nhap.isdigit() or ...: nhờ cơ chế "đoản mạch", nếu vế trái đúng (không phải số) thì Python không tính vế phải, nên int(nhap) không bị gọi với chuỗi chữ.

Bài 2. Tiền điện cho nhiều mức

Tính tiền điện (chưa thuế) cho 50, 51, 150 và 420 kWh. Kiểm tra bằng tay ít nhất một giá trị.

Xem đáp án 
BAC_GIA = [(50, 1984), (100, 2050), (200, 2380), (300, 2998), (400, 3350), (None, 3460)]

for so_kwh in [50, 51, 150, 420]:
    con_lai, muc_duoi, tong = so_kwh, 0, 0
    for muc_tran, gia in BAC_GIA:
        if con_lai <= 0:
            break
        do_rong = con_lai if muc_tran is None else muc_tran - muc_duoi
        kwh_bac = min(con_lai, do_rong)
        tong += kwh_bac * gia
        con_lai -= kwh_bac
        muc_duoi = muc_tran or muc_duoi
    print(f"{so_kwh:>4} kWh: {tong:>10,} đ")
  50 kWh:     99,200 đ
  51 kWh:    101,250 đ
 150 kWh:    320,700 đ
 420 kWh:  1,143,700 đ

Tính tay 420 kWh: 99.200 + 102.500 + 238.000 + 299.800 + 335.000 + 20 × 3.460 = 1.143.700 đ. Đoạn code tính tiền đang bị chép lại ở hai nơi; ở chặng 2 bạn sẽ gói nó thành hàm tinh_tien_dien(so_kwh) để dùng lại.
