"Chạy được trên máy tôi" là câu nói quen thuộc khi đưa phần mềm AI sang máy khác: khác phiên bản Python, thiếu thư viện hệ thống, sai bản CUDA. Docker đóng gói ứng dụng cùng toàn bộ môi trường của nó thành một container chạy giống nhau ở mọi nơi.

Khái niệm cơ bản

  • Image: "bản thiết kế" chứa hệ điều hành tối giản, thư viện, code của bạn. Tạo từ file Dockerfile.
  • Container: một phiên chạy của image, cô lập với hệ thống bên ngoài.
  • Registry: kho lưu image (Docker Hub hoặc registry nội bộ của công ty).

Dockerfile cho ứng dụng vision Python

FROM python:3.11-slim

# Thư viện hệ thống mà OpenCV cần
RUN apt-get update && apt-get install -y --no-install-recommends libgl1 libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY src/ ./src/
COPY models/ ./models/

CMD ["python", "src/main.py"]

Thứ tự lệnh quan trọng: copy requirements.txt và cài thư viện trước khi copy code, để mỗi lần sửa code Docker không phải cài lại thư viện (tận dụng bộ nhớ đệm từng lớp).

Build và chạy

docker build -t tram-vision:1.0 .
docker run --rm -v D:/anh-test:/data -p 8000:8000 tram-vision:1.0
  • -v: gắn thư mục máy thật vào container để đọc ảnh, ghi kết quả.
  • -p: mở cổng mạng (ví dụ API web của ứng dụng).

Dùng GPU NVIDIA trong container

Cài driver NVIDIA và NVIDIA Container Toolkit trên máy chủ, rồi chạy:

docker run --rm --gpus all tram-vision-gpu:1.0

Image cho GPU thường dựa trên image có sẵn CUDA hoặc image chính thức của framework (PyTorch, TensorRT). Driver trên máy chủ phải đủ mới so với phiên bản CUDA trong image.

Thói quen tốt

  • Gắn phiên bản cụ thể cho image (tram-vision:1.0.3), không chỉ dùng latest.
  • Ghi phiên bản thư viện cố định trong requirements.txt.
  • Không đưa mật khẩu, khóa API vào image; truyền qua biến môi trường hoặc cơ chế quản lý bí mật.
  • Giữ image gọn: dùng image nền "slim", xóa bộ nhớ đệm sau khi cài.
