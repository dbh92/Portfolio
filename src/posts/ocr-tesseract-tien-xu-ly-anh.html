Tesseract là bộ OCR mã nguồn mở lâu đời và phổ biến, hỗ trợ hơn 100 ngôn ngữ kể cả tiếng Việt. Nó đọc rất tốt văn bản in rõ ràng, nhưng nếu đưa thẳng ảnh chụp thực tế vào thì kết quả thường tệ. Bí quyết nằm ở tiền xử lý ảnh.

Cài đặt

  • Cài chương trình Tesseract cho hệ điều hành (Windows có bộ cài sẵn; Ubuntu: sudo apt install tesseract-ocr tesseract-ocr-vie).
  • Cài thư viện Python: pip install pytesseract opencv-python.
import pytesseract
# Windows: chỉ đường dẫn nếu chưa có trong PATH

Thử nghiệm ban đầu

import cv2
img = cv2.imread("nhan-san-pham.png")
text = pytesseract.image_to_string(cv2.cvtColor(img, cv2.COLOR_BGR2RGB), lang="eng")
print(text)

Tiền xử lý: biến ảnh thực tế thành "trang sách"

Tesseract hoạt động tốt nhất với chữ đen trên nền trắng, nét rõ, chiều cao chữ khoảng 20–40 pixel, dòng thẳng.

import numpy as np

def preprocess(bgr):
    gray = cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)
    # 1. phóng to nếu chữ nhỏ
    gray = cv2.resize(gray, None, fx=2, fy=2, interpolation=cv2.INTER_CUBIC)
    # 2. tăng tương phản cục bộ
    gray = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8)).apply(gray)
    # 3. giảm nhiễu nhưng giữ biên
    gray = cv2.bilateralFilter(gray, 9, 50, 50)
    # 4. nhị phân, đảm bảo chữ đen nền trắng
    _, th = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    if np.mean(th) < 127:          # nền đen -> đảo
        th = 255 - th
    return th

clean = preprocess(img)

Với chữ in phun dạng chấm, thêm bước giãn (dilate) nhẹ để nối các chấm thành nét liền trước khi đọc (chú ý: trên ảnh chữ đen nền trắng, cần đảo ảnh, giãn, rồi đảo lại).

Chế độ phân đoạn trang (PSM) và giới hạn ký tự

config = "--psm 7 -c tessedit_char_whitelist=0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ-/"
code = pytesseract.image_to_string(clean, lang="eng", config=config).strip()
  • --psm 7: ảnh là một dòng chữ. --psm 8: một từ. --psm 6: một khối văn bản.
  • Whitelist chỉ cho phép các ký tự có thể xuất hiện, giảm mạnh nhầm lẫn.

Lấy vị trí và độ tin cậy từng từ

data = pytesseract.image_to_data(clean, config="--psm 6", output_type=pytesseract.Output.DICT)
for word, conf, x, y, w, h in zip(data["text"], data["conf"], data["left"],
                                  data["top"], data["width"], data["height"]):
    if word.strip():
        print(word, conf, (x, y, w, h))

Dùng độ tin cậy để quyết định: dưới ngưỡng thì báo người vận hành kiểm tra, không tự đoán.
