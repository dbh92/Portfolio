OpenCV là thư viện xử lý ảnh mã nguồn mở phổ biến nhất thế giới, dùng được từ Python, C++, C# (qua OpenCvSharp) và chạy trên hầu hết phần cứng. Bài này giúp bạn làm chủ ba việc cơ bản nhất: đọc/ghi ảnh, xử lý video và lấy hình từ camera.

Cài đặt

python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install opencv-python numpy

Gói opencv-python có giao diện cửa sổ (imshow). Trên máy chủ không màn hình, dùng opencv-python-headless. Đừng cài cả hai cùng lúc vì chúng xung đột nhau.

Đọc, hiển thị, ghi ảnh

import cv2

img = cv2.imread("san-pham.jpg")
if img is None:                       # imread KHÔNG báo lỗi khi sai đường dẫn
    raise FileNotFoundError("Không đọc được ảnh")

cv2.imshow("Anh goc", img)
cv2.waitKey(0)                        # chờ bấm phím
cv2.destroyAllWindows()

cv2.imwrite("ket-qua.png", img)       # PNG không nén mất dữ liệu
cv2.imwrite("ket-qua.jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 95])

Hai lưu ý quan trọng: cv2.imread trả về None thay vì báo lỗi, và trên Windows nó không đọc được đường dẫn có dấu tiếng Việt. Cách xử lý đường dẫn Unicode:

import numpy as np
data = np.fromfile("D:/Ảnh mẫu/lỗi-01.png", dtype=np.uint8)
img = cv2.imdecode(data, cv2.IMREAD_COLOR)

Đổi không gian màu

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
hsv  = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

# Lọc màu đỏ trong HSV (OpenCV dùng H: 0-179)
mask1 = cv2.inRange(hsv, (0, 80, 60), (10, 255, 255))
mask2 = cv2.inRange(hsv, (170, 80, 60), (179, 255, 255))
red_mask = cv2.bitwise_or(mask1, mask2)

HSV tách màu sắc (H) khỏi độ sáng (V), nên lọc màu ổn định hơn nhiều so với lọc trực tiếp trên BGR khi ánh sáng thay đổi.

Vẽ kết quả lên ảnh

cv2.rectangle(img, (50, 40), (220, 180), (0, 255, 0), 2)
cv2.circle(img, (300, 200), 25, (255, 0, 0), -1)          # -1 = tô kín
cv2.putText(img, "OK", (50, 30), cv2.FONT_HERSHEY_SIMPLEX, 1.0, (0, 255, 0), 2)

putText không hỗ trợ tiếng Việt có dấu; nếu cần, vẽ chữ bằng thư viện Pillow.

Đọc video và camera

cap = cv2.VideoCapture(0)              # 0 = camera đầu tiên; hoặc "video.mp4"
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)

while True:
    ok, frame = cap.read()
    if not ok:
        break
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    cv2.imshow("Camera", gray)
    if cv2.waitKey(1) & 0xFF == ord("q"):   # bấm q để thoát
        break

cap.release()
cv2.destroyAllWindows()

VideoCapture dùng tốt cho webcam USB. Camera công nghiệp chuẩn GigE Vision/USB3 Vision thường cần SDK của hãng (hoặc thư viện như Harvesters), sau đó chuyển khung hình sang mảng NumPy để xử lý bằng OpenCV như bình thường.

Bài tập

  1. Mở webcam, hiển thị song song ảnh màu và ảnh xám.
  2. Vẽ một khung ROI cố định giữa màn hình và in độ sáng trung bình của ROI lên ảnh theo thời gian thực.
  3. Bấm phím s để lưu khung hình hiện tại thành file PNG có tên theo thời gian.

Bài tiếp theo: phân ngưỡng và contour để đếm, đo vật thể.
