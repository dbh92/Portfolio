Đây là bài đầu tiên của lộ trình. Bạn chưa cần biết gì về lập trình. Kết thúc bài này, máy của bạn sẽ có Python và VS Code, bạn tự viết và chạy được chương trình đầu tiên, và biết cách đọc thông báo lỗi. Bước này nhỏ, nhưng không làm đúng sẽ vướng ở mọi bài sau.

Vì sao kỹ sư Vision học Python?

Python là ngôn ngữ chung của Computer Vision và AI: OpenCV, NumPy, PyTorch, YOLO đều dùng Python đầu tiên. Bạn dùng Python để thử nghiệm thuật toán, huấn luyện mô hình, viết công cụ xử lý dữ liệu. Khi triển khai, một số nhà máy dùng C# hoặc C++, nhưng gần như mọi dự án đều bắt đầu bằng Python.

Bước 1: cài Python

Nên chọn Python 3.13 hoặc 3.14. Đây là các bản ổn định mà OpenCV, NumPy và PyTorch đều hỗ trợ. Bản vừa ra mắt đôi khi chưa có đủ thư viện AI, nên đừng vội cài bản mới nhất. Lộ trình này dùng Python 3.13.

Windows

Từ Python 3.14, cách được khuyến nghị trên Windows là Python install manager:

  1. Mở Microsoft Store, tìm "Python install manager" và cài. Hoặc tải từ python.org/downloads/windows.
  2. Mở Terminal (hoặc PowerShell) và gõ lệnh cài Python 3.13:
py install 3.13
py list

py list liệt kê các bản Python đã cài và cho biết bản nào là mặc định. Gõ py help để xem mọi lệnh của trình quản lý.

Bạn vẫn có thể dùng bộ cài truyền thống (file .exe trên python.org). Khi cài, nhớ tích ô "Add python.exe to PATH" ở màn hình đầu tiên. Quên bước này là lỗi phổ biến nhất của người mới.

Bẫy trên Windows: "python" mở ra Microsoft StoreWindows có sẵn một lệnh python "giả" chỉ để mở Store. Nếu gõ python mà Store hiện ra, hãy dùng lệnh py thay thế, hoặc tắt "App execution aliases" cho python.exe trong Settings → Apps → Advanced app settings.

macOS

Tải bộ cài macOS trên python.org/downloads, chạy và làm theo hướng dẫn. Trên macOS, lệnh là python3 (không phải python).

Linux (Ubuntu)

Ubuntu có sẵn Python 3. Cài thêm công cụ tạo môi trường ảo và pip:

sudo apt update
sudo apt install python3 python3-venv python3-pip

Kiểm tra cài đặt

Mở terminal mới (terminal cũ không nhận PATH mới) và gõ:

python --version      # Windows: hoặc  py --version
python3 --version     # macOS / Linux
Python 3.13.x

Thấy số phiên bản là bạn đã cài thành công. Từ đây, khi bài viết ghi python, người dùng macOS/Linux hãy gõ python3, người dùng Windows có thể gõ py.

Bước 2: cài VS Code và tiện ích Python

  1. Tải VS Code tại code.visualstudio.com và cài đặt.
  2. Mở VS Code, bấm biểu tượng Extensions (Ctrl+Shift+X), tìm Python của Microsoft và cài. Tiện ích này cài kèm Pylance (gợi ý code) và trình debug.
  3. Tạo một thư mục cho việc học, ví dụ D:\hoc-python hoặc ~/hoc-python. Trong VS Code chọn File → Open Folder và mở thư mục đó.
MẹoĐặt tên thư mục và file không dấu, không khoảng trắng (ví dụ hoc-python, bai_1.py). Nhiều công cụ AI và OpenCV bản cũ đọc sai đường dẫn có dấu tiếng Việt.

Bước 3: chương trình đầu tiên

Trong VS Code, tạo file mới tên hello.py và gõ:

print("Xin chào, tôi đang học Python để trở thành Vision Engineer!")
print("2 + 3 =", 2 + 3)

Có hai cách chạy:

  • Nút Run (hình tam giác ▷ góc trên bên phải VS Code).
  • Terminal: mở terminal trong VS Code (Ctrl+`) rồi gõ python hello.py.
Xin chào, tôi đang học Python để trở thành Vision Engineer!
2 + 3 = 5

Hàm print() in ra màn hình những gì bạn đưa vào trong ngoặc. Chữ đặt trong dấu nháy "..." là chuỗi (văn bản); số và phép tính viết trực tiếp.

Nếu VS Code hỏi chọn interpreter, hãy chọn bản Python 3.13 vừa cài (Ctrl+Shift+P → "Python: Select Interpreter").

Bước 4: thử nhanh trong chế độ tương tác

Gõ python (không kèm tên file) trong terminal để vào chế độ tương tác. Dấu nhắc >>> xuất hiện, bạn gõ lệnh nào là chạy ngay lệnh đó, rất tiện để thử nhanh:

>>> 1920 * 1080
2073600
>>> 2073600 / 1_000_000
2.0736
>>> exit()

Ví dụ trên tính số điểm ảnh của camera Full HD: khoảng 2,07 megapixel. Gõ exit() để thoát.

Bước 5: đọc thông báo lỗi

Lập trình viên giỏi không phải người không gặp lỗi, mà là người đọc lỗi nhanh. Thử chạy file này:

# (minh họa) Chương trình có lỗi chính tả: prin thay vì print
prin("Kiểm tra camera")
Traceback (most recent call last):
  File "D:\hoc-python\hello.py", line 2, in <module>
    prin("Kiểm tra camera")
    ^^^^
NameError: name 'prin' is not defined. Did you mean: 'print'?

Đọc lỗi từ dưới lên:

  1. Dòng cuối cho biết loại lỗi và lý do: NameError, tên prin chưa được định nghĩa. Python còn gợi ý: có phải bạn muốn viết print?
  2. Dòng phía trên chỉ ra file và số dòng: line 2.

Ba lỗi bạn sẽ gặp nhiều nhất trong tuần đầu:

LỗiNguyên nhân thường gặpCách sửa
NameErrorGõ sai tên hàm/biến, hoặc dùng biến trước khi tạoKiểm tra chính tả, thứ tự dòng
SyntaxErrorThiếu dấu ngoặc, dấu nháy, dấu hai chấmXem vị trí dấu ^ Python chỉ ra
IndentationErrorThụt lề sai (Python dùng thụt lề để nhóm lệnh)Dùng 4 dấu cách, không trộn Tab và dấu cách

Tóm tắt

  • Cài Python 3.13 (Windows: Python install manager hoặc bộ cài nhớ tích "Add to PATH").
  • Cài VS Code + tiện ích Python, mở thư mục học tập không dấu.
  • Chạy file bằng nút Run hoặc lệnh python ten_file.py.
  • Đọc lỗi từ dưới lên: loại lỗi → lý do → số dòng.

Bài tập

Bài 1. Giới thiệu bản thân

Viết file gioi_thieu.py in ra 3 dòng: tên của bạn, công việc hiện tại, và lý do bạn học Vision.

Xem đáp án 
print("Tên: Nguyễn Văn An")
print("Công việc: kỹ thuật viên bảo trì")
print("Mục tiêu: trở thành Vision Engineer trong 12 tháng")

Bài 2. Tính nhanh thông số camera

Camera có độ phân giải 2448 × 2048 pixel. In ra tổng số pixel và số megapixel (chia cho 1.000.000).

Xem đáp án 
print("Tổng số pixel:", 2448 * 2048)
print("Megapixel:", 2448 * 2048 / 1_000_000)
Tổng số pixel: 5013504
Megapixel: 5.013504

Đây là camera 5 MP, loại rất phổ biến trong Machine Vision.

Bài 3. Sửa lỗi

Chương trình sau có 2 lỗi. Chạy thử, đọc thông báo lỗi và sửa cho đến khi chạy được.

# (minh họa) chương trình có lỗi để bạn tự sửa
print("Bắt đầu kiểm tra)
Print("Kết thúc")
Xem đáp án

Lỗi 1: thiếu dấu nháy đóng ở dòng 2 (SyntaxError: unterminated string literal). Lỗi 2: Print viết hoa, Python phân biệt chữ hoa chữ thường (NameError).

print("Bắt đầu kiểm tra")
print("Kết thúc")

Bài tiếp theo: bạn sẽ học cách lưu dữ liệu vào biến và làm việc với các kiểu dữ liệu số, chuỗi, đúng/sai.
