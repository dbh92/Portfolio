Mọi chương trình đều làm ba việc: nhận dữ liệu, xử lý dữ liệu và đưa ra kết quả. Bài này dạy bạn cách Python lưu dữ liệu (biến và kiểu dữ liệu), cách tính toán, so sánh (toán tử) và cách nhận dữ liệu từ người dùng (input()).

1. Biến là nhãn dán lên giá trị

gia = 45000
ten_san_pham = "Cà phê sữa"
gia = gia + 5000          # gán lại: nhãn "gia" dán sang giá trị mới
print(ten_san_pham, gia)
Cà phê sữa 50000

Dấu = trong Python là gán, không phải "bằng" như trong toán. Dòng gia = gia + 5000 nghĩa là: tính gia + 5000, rồi dán nhãn gia lên kết quả. Không cần khai báo kiểu trước; Python tự biết kiểu từ giá trị.

Quy tắc đặt tên: chữ cái, số, dấu gạch dưới, không bắt đầu bằng số, phân biệt hoa thường. Theo chuẩn PEP 8, tên biến viết chữ thường nối bằng gạch dưới (so_luong, tong_tien), hằng số viết hoa (THUE_VAT = 0.08). Tên tiếng Việt không dấu hay tiếng Anh đều được, miễn nhất quán và có nghĩa: tong_tien tốt hơn tt hay x.

print(a ** 2)                # lũy thừa: 289

// và % rất hay dùng: đổi phút sang giờ, kiểm tra số chẵn (n % 2 == 0), chia trang. Thứ tự ưu tiên giống toán: ** trước, rồi * / // %, rồi + -. Khi phân vân, thêm ngoặc cho rõ.

Toán tử gán rút gọn: x += 1 tương đương x = x + 1; tương tự -=, *=, /=.

Số thực không chính xác tuyệt đối0.1 + 0.2 cho 0.30000000000000004 vì máy tính lưu số thực ở hệ nhị phân. Đừng so sánh hai số thực bằng ==; dùng math.isclose(a, b). Với tiền tệ, hãy tính bằng số nguyên (đồng) hoặc dùng module decimal.

4. So sánh và logic

tuoi = 20
co_ve = True

print(tuoi >= 18)                    # True
print(tuoi == 20, tuoi != 20)        # True False
print(18 <= tuoi < 60)              # so sánh nối chuỗi: True
print(tuoi >= 18 and co_ve)         # True
print(not co_ve or tuoi < 16)       # False
True
True False
True
True
False

Kết quả so sánh là bool. Kết hợp bằng and, or, not. Python cho phép viết 18 <= tuoi < 60 giống toán học, gọn hơn nhiều ngôn ngữ khác.

Khi dùng trong điều kiện, mọi giá trị đều được xét là "đúng" hoặc "sai": 0, 0.0, "" (chuỗi rỗng), None, list rỗng là sai; còn lại là đúng. Để kiểm tra None, viết x is None chứ không viết x == None.

6. Nhận dữ liệu bằng input()

input() in lời nhắc, chờ người dùng gõ và nhấn Enter, rồi luôn trả về chuỗi. Muốn tính toán phải ép kiểu:

ten = input("Tên bạn: ")
nam_sinh = int(input("Năm sinh: "))
print(f"Chào {ten}, năm 2030 bạn {2030 - nam_sinh} tuổi.")
Tên bạn: Hoa
Năm sinh: 2003
Chào Hoa, năm 2030 bạn 27 tuổi.

Nếu người dùng gõ chữ thay vì số, int() báo ValueError. Ở chặng 3 bạn sẽ học try/except để hỏi lại thay vì để chương trình dừng. Người Việt hay gõ dấu phẩy thập phân (1,65); trước khi gọi float() có thể đổi bằng .replace(",", ".").

Tóm tắt

  • = là gán; tên biến chữ thường, gạch dưới, có nghĩa.
  • 5 kiểu cơ bản: int, float, str, bool, None; xem kiểu bằng type().
  • / luôn ra float; // lấy phần nguyên, % lấy dư, ** lũy thừa.
  • Không so sánh số thực bằng ==; dùng math.isclose.
  • input() trả về chuỗi, nhớ ép kiểu bằng int(), float().

Bài tập

Bài 1. Tính BMI

Nhập chiều cao (m, chấp nhận cả dấu phẩy) và cân nặng (kg), in BMI = cân nặng / chiều cao² với 1 chữ số thập phân.

Xem đáp án 
chieu_cao = float(input("Chiều cao (m): ").replace(",", "."))
can_nang = float(input("Cân nặng (kg): ").replace(",", "."))
bmi = can_nang / chieu_cao ** 2
print(f"BMI của bạn: {bmi:.1f}")
Chiều cao (m): 1,65
Cân nặng (kg): 58
BMI của bạn: 21.3

chieu_cao ** 2 được tính trước phép chia vì ** ưu tiên cao hơn. :.1f trong f-string nghĩa là in số thực với 1 chữ số thập phân.

Bài 2. Đổi giây ra giờ, phút, giây

Nhập số giây, ví dụ 7385, in 2 giờ 3 phút 5 giây.

Xem đáp án 
tong_giay = 7385
gio = tong_giay // 3600
phut = tong_giay % 3600 // 60
giay = tong_giay % 60
print(f"{gio} giờ {phut} phút {giay} giây")
2 giờ 3 phút 5 giây

Thay dòng đầu bằng tong_giay = int(input("Số giây: ")) để nhập từ bàn phím. Cách khác gọn hơn: gio, du = divmod(tong_giay, 3600) trả về cả thương và số dư một lúc.
