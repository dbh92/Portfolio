Bài đầu tiên của lộ trình Python Developer chỉ có một mục tiêu: máy của bạn chạy được Python, bạn viết được một file .py, chạy nó và khi có lỗi thì biết đọc thông báo lỗi để tự sửa. Ba kỹ năng này bạn sẽ dùng mỗi ngày trong suốt nghề lập trình.

1. Chọn phiên bản Python nào?

Python phát hành một bản lớn mỗi tháng 10 và hỗ trợ mỗi bản trong 5 năm. Tại thời điểm viết bài (cuối tháng 10/2026):

Phiên bảnRa mắtTrạng thái
3.1509/10/2026Mới nhất, đang sửa lỗi
3.1407/10/2025Ổn định, đang sửa lỗi
3.12, 3.132023, 2024Chỉ còn vá bảo mật
3.102021Hết hỗ trợ từ 10/2026, không nên cài mới

Hãy cài 3.14 hoặc 3.15. Mọi code trong lộ trình chạy trên Python 3.12 trở lên. Đừng lo "học bản cũ hay bản mới": cú pháp cơ bản gần như không đổi giữa các bản 3.x.

2. Cài Python

Windows

Từ Python 3.14, cách cài khuyến nghị trên Windows là Python install manager, tải ở python.org/downloads hoặc cài từ Microsoft Store (hai bản giống nhau). Sau khi cài, mở Terminal (PowerShell) và gõ:

PS> py install 3.14
PS> py list
PS> python --version
Python 3.14.10

Lệnh py install tải và cài một phiên bản, py list liệt kê các bản đã cài. Bộ cài .exe truyền thống vẫn có cho 3.14 và 3.15 nhưng đã bị đánh dấu ngừng phát triển: từ 3.16 sẽ không còn. Nếu bạn dùng bộ cài .exe, nhớ tích ô Add python.exe to PATH ở màn hình đầu tiên.

macOS và Linux

macOS: tải bộ cài .pkg ở python.org. Linux (Ubuntu, Debian): Python 3 thường có sẵn, kiểm tra bằng python3 --version; trên macOS và Linux bạn gõ python3 thay cho python. Ở chặng 6 bạn sẽ học uv, công cụ cài và chuyển đổi phiên bản Python trên cả ba hệ điều hành chỉ bằng một lệnh.

Lỗi hay gặp trên WindowsGõ python mà Microsoft Store tự mở ra, hoặc báo "Python was not found": Python chưa được cài hoặc chưa nằm trong PATH. Cài lại bằng install manager, sau đó đóng và mở lại Terminal để PATH mới có hiệu lực.

3. Cài VS Code và extension Python

  1. Tải VS Code ở code.visualstudio.com và cài với thiết lập mặc định.
  2. Mở VS Code, bấm biểu tượng Extensions (Ctrl+Shift+X), tìm Python của Microsoft và cài. Extension này kéo theo Pylance (gợi ý code, báo lỗi) và Python Debugger.
  3. Tạo thư mục hoc-python, chọn File › Open Folder để mở thư mục đó. Luôn mở cả thư mục, không mở lẻ từng file.
  4. Bấm Ctrl+Shift+P, gõ Python: Select Interpreter và chọn bản Python vừa cài.

4. Ba cách chạy code Python

REPL: thử nhanh từng dòng

Gõ python trong Terminal để vào chế độ tương tác (REPL). Dấu nhắc >>> chờ bạn gõ lệnh, Python chạy ngay và in kết quả:

>>> 2 + 3 * 4
14
>>> "Xin chào " * 2
'Xin chào Xin chào '
>>> exit()

REPL hợp để thử một hàm hay một phép tính. Chương trình thật thì viết vào file.

File .py chạy bằng terminal

Trong VS Code, tạo file chao.py:

ten = "Lan"
nam_sinh = 2001
tuoi = 2026 - nam_sinh

print("Xin chào, tôi là", ten)
print(f"Năm nay tôi {tuoi} tuổi.")

Mở terminal tích hợp bằng Ctrl+` và chạy:

PS D:\hoc-python> python chao.py
Xin chào, tôi là Lan
Năm nay tôi 25 tuổi.

Python chạy file từ trên xuống dưới, từng dòng một. print() in ra màn hình; chuỗi có chữ f đứng trước cho phép chèn giá trị biến vào trong cặp ngoặc nhọn {}.

Nút Run trong VS Code

Bấm nút tam giác ▷ ở góc trên bên phải khi đang mở file .py. VS Code mở terminal và chạy đúng lệnh như trên. Dùng nút cho nhanh, nhưng hãy thuộc cách chạy bằng lệnh vì máy chủ, Docker hay lịch chạy tự động đều chạy theo cách đó.

5. Đọc thông báo lỗi (traceback)

Người mới thường sợ chữ đỏ. Thực ra traceback là bản chỉ đường: nó nói lỗi gì, ở file nào, dòng nào. Thử chương trình sai sau:

# (minh họa) chương trình cố ý có lỗi
gia = 25000
so_luong = "3"
print("Tổng:", gia * so_luong + 1000)
Traceback (most recent call last):
  File "D:\hoc-python\loi.py", line 4, in <module>
    print("Tổng:", gia * so_luong + 1000)
                   ~~~~~~~~~~~~~~~^~~~~~
TypeError: can only concatenate str (not "int") to str

Đọc theo thứ tự:

  1. Dòng cuối trước tiên: loại lỗi (TypeError) và mô tả. Ở đây: không thể nối chuỗi với số nguyên.
  2. Dòng File ..., line 4: lỗi nằm ở dòng 4. Bấm Ctrl + click vào đường dẫn trong terminal VS Code để nhảy tới đúng dòng.
  3. Dấu ^ và ~ chỉ chính xác phần biểu thức gây lỗi.

Nguyên nhân: so_luong là chuỗi "3", nên gia * so_luong lặp chuỗi "3" 25.000 lần thành một chuỗi rất dài, rồi cộng chuỗi đó với số 1000 thì lỗi. Sửa: so_luong = 3. Bạn sẽ học kỹ về kiểu dữ liệu ở bài sau.

Ba loại lỗi gặp nhiều nhất tuần đầu:

LỗiNghĩaNguyên nhân thường gặp
SyntaxErrorSai cú phápThiếu dấu :, thiếu ngoặc, quên đóng nháy
NameErrorTên chưa được định nghĩaGõ sai tên biến, dùng biến trước khi gán
IndentationErrorThụt lề saiTrộn tab và dấu cách, thụt lề không đều
Thói quen tốtMỗi lần gặp lỗi mới, chép dòng cuối của traceback vào một file ghi chú kèm cách sửa. Sau một tháng bạn sẽ có "từ điển lỗi" của riêng mình và sửa lỗi nhanh hơn nhiều.

Tóm tắt

  • Cài Python 3.14 hoặc 3.15; trên Windows dùng Python install manager (py install, py list).
  • VS Code + extension Python; luôn mở cả thư mục dự án và chọn đúng interpreter.
  • REPL để thử nhanh, file .py chạy bằng python ten_file.py cho chương trình thật.
  • Đọc traceback từ dòng cuối: loại lỗi, rồi số dòng, rồi dấu ^.

Bài tập

Bài 1. Chương trình giới thiệu

Viết chao.py lưu tên, năm sinh vào biến, in ra tên, năm sinh và tuổi năm nay. Chạy bằng terminal.

Xem đáp án 
ten = "Minh"
nam_sinh = 1998
nam_nay = 2026

print(f"Tên: {ten}")
print(f"Năm sinh: {nam_sinh}")
print(f"Tuổi năm nay: {nam_nay - nam_sinh}")
Tên: Minh
Năm sinh: 1998
Tuổi năm nay: 28

Ở bài sau bạn sẽ dùng module datetime để lấy năm hiện tại tự động thay vì gõ tay 2026.

Bài 2. Sửa ba chương trình lỗi

Mỗi đoạn dưới đây có một lỗi. Chạy thử, đọc dòng cuối traceback, đoán loại lỗi rồi sửa.

# (minh họa) đoạn A
print("Xin chào"
# (minh họa) đoạn B
diem = 8
print(diem_tb)
# (minh họa) đoạn C
if 5 > 3:
print("Đúng")
Xem đáp án
  • Đoạn A: SyntaxError: '(' was never closed. Thêm dấu ) cuối dòng.
  • Đoạn B: NameError: name 'diem_tb' is not defined. Did you mean: 'diem'?. Python còn gợi ý tên đúng; sửa thành print(diem).
  • Đoạn C: IndentationError: expected an indented block after 'if' statement on line 1. Thụt lề dòng print vào 4 dấu cách.
