U-Net ra đời năm 2015 cho phân đoạn ảnh y sinh và đến nay vẫn là kiến trúc được dùng nhiều nhất cho semantic segmentation khi dữ liệu ít, ví dụ phân đoạn vết nứt, vùng thiếu keo, vết loang. Bài này giải thích ý tưởng và cài đặt một U-Net nhỏ bằng PyTorch.

Ý tưởng: chữ U

  • Nhánh mã hóa (encoder): các lớp tích chập và giảm kích thước, học "cái gì" có trong ảnh.
  • Nhánh giải mã (decoder): phóng to dần về kích thước ban đầu, xác định "ở đâu".
  • Kết nối tắt (skip connection): nối đặc trưng chi tiết từ encoder sang decoder cùng tầng, giúp biên mặt nạ sắc nét. Đây là điểm làm nên thành công của U-Net.

Cài đặt U-Net nhỏ

import torch
from torch import nn

def block(cin, cout):
    return nn.Sequential(
        nn.Conv2d(cin, cout, 3, padding=1), nn.BatchNorm2d(cout), nn.ReLU(inplace=True),
        nn.Conv2d(cout, cout, 3, padding=1), nn.BatchNorm2d(cout), nn.ReLU(inplace=True),
    )

class UNet(nn.Module):
    def __init__(self, in_ch=1, n_classes=1, base=16):
        super().__init__()
        self.e1, self.e2, self.e3 = block(in_ch, base), block(base, base * 2), block(base * 2, base * 4)
        self.pool = nn.MaxPool2d(2)
        self.mid = block(base * 4, base * 8)
        self.up3, self.d3 = nn.ConvTranspose2d(base * 8, base * 4, 2, 2), block(base * 8, base * 4)
        self.up2, self.d2 = nn.ConvTranspose2d(base * 4, base * 2, 2, 2), block(base * 4, base * 2)
        self.up1, self.d1 = nn.ConvTranspose2d(base * 2, base, 2, 2), block(base * 2, base)
        self.out = nn.Conv2d(base, n_classes, 1)

    def forward(self, x):
        e1 = self.e1(x)
        e2 = self.e2(self.pool(e1))
        e3 = self.e3(self.pool(e2))
        m = self.mid(self.pool(e3))
        d3 = self.d3(torch.cat([self.up3(m), e3], 1))     # skip connection
        d2 = self.d2(torch.cat([self.up2(d3), e2], 1))
        d1 = self.d1(torch.cat([self.up1(d2), e1], 1))
        return self.out(d1)                               # logits, chưa qua sigmoid

net = UNet()
print(net(torch.randn(2, 1, 256, 256)).shape)             # [2, 1, 256, 256]

Kích thước ảnh đầu vào nên chia hết cho 8 (ba lần giảm một nửa).

Hàm mất mát cho vùng lỗi nhỏ

Vết lỗi thường chỉ chiếm 1% diện tích ảnh; dùng riêng Binary Cross-Entropy, mô hình dễ "lười" dự đoán toàn nền. Kết hợp với Dice loss:

def dice_loss(logits, target, eps=1.0):
    p = torch.sigmoid(logits)
    inter = (p * target).sum(dim=(1, 2, 3))
    union = p.sum(dim=(1, 2, 3)) + target.sum(dim=(1, 2, 3))
    return 1 - ((2 * inter + eps) / (union + eps)).mean()

bce = nn.BCEWithLogitsLoss()
def loss_fn(logits, mask):          # mask: 0/1, dạng float, cùng kích thước logits
    return bce(logits, mask) + dice_loss(logits, mask)

Huấn luyện và suy luận

  • Vòng lặp huấn luyện giống hệt bài PyTorch cơ bản, chỉ thay hàm mất mát.
  • Augmentation phải áp dụng đồng thời cho ảnh và mặt nạ (lật, xoay cùng một cách).
  • Suy luận: mask = torch.sigmoid(net(x)) > 0.5, sau đó dùng OpenCV tìm contour để đo vùng lỗi.

Đi xa hơn

Thay encoder tự viết bằng một mạng đã huấn luyện sẵn (ResNet, EfficientNet) giúp mô hình hội tụ nhanh hơn với ít dữ liệu. Các thư viện mã nguồn mở về segmentation cung cấp sẵn U-Net với nhiều encoder pretrained để thử nghiệm nhanh.
