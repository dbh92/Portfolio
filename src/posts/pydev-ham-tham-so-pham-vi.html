Ở bài thực hành tiền điện, đoạn code tính tiền bị chép lại hai lần. Sửa giá thì phải sửa hai chỗ, quên một chỗ là sai. Hàm giải quyết đúng vấn đề đó: đặt tên cho một đoạn code, gọi lại bao nhiêu lần cũng được. Viết hàm tốt là kỹ năng quan trọng nhất để chuyển từ "viết script" sang "viết phần mềm".

1. Định nghĩa, gọi và trả về

def tinh_tien_dien(so_kwh: int) -> int:
    """Tiền điện sinh hoạt (đồng, chưa thuế) theo 6 bậc."""
    bac_gia = [(50, 1984), (100, 2050), (200, 2380), (300, 2998), (400, 3350), (None, 3460)]
    con_lai, muc_duoi, tong = so_kwh, 0, 0
    for muc_tran, gia in bac_gia:
        if con_lai <= 0:
            break
        do_rong = con_lai if muc_tran is None else muc_tran - muc_duoi
        kwh = min(con_lai, do_rong)
        tong += kwh * gia
        con_lai -= kwh
        muc_duoi = muc_tran or muc_duoi
    return tong


print(tinh_tien_dien(150))
print(tinh_tien_dien(50) + tinh_tien_dien(51))
320700
200450
  • def, tên hàm (động từ, chữ thường), tham số trong ngoặc, dấu :, thân hàm thụt lề.
  • Chuỗi ngay dưới def là docstring; VS Code hiện nó khi rê chuột lên tên hàm.
  • so_kwh: int và -> int là type hint: ghi chú kiểu, giúp VS Code gợi ý và cảnh báo. Python không kiểm tra khi chạy.
  • return trả kết quả và kết thúc hàm ngay. Hàm không có return trả về None.
Trả kết quả, đừng inHàm return kết quả thì dùng được ở mọi nơi: cộng, so sánh, ghi file, trả qua API. Hàm chỉ print thì chỉ dùng được để xem. Để việc in ấn cho phần chương trình chính.

2. Các kiểu tham số

def chao(ten, loi_chao="Xin chào", dau_cau="!"):
    return f"{loi_chao}, {ten}{dau_cau}"


print(chao("An"))                              # dùng giá trị mặc định
print(chao("Bình", "Chào buổi sáng"))          # theo vị trí
print(chao("Chi", dau_cau="."))                # theo tên, bỏ qua tham số giữa
print(chao(loi_chao="Hello", ten="Dũng"))      # theo tên, thứ tự tùy ý
Xin chào, An!
Chào buổi sáng, Bình!
Xin chào, Chi.
Hello, Dũng!

Tham số có giá trị mặc định phải đứng sau tham số bắt buộc. Gọi theo tên giúp code tự giải thích, nhất là với tham số kiểu True/False: xuat_bao_cao(du_lieu, gui_email=True) dễ hiểu hơn xuat_bao_cao(du_lieu, True).

Đặt * trong danh sách tham số để bắt buộc các tham số phía sau phải gọi theo tên:

def chuyen_tien(so_tien, *, tu_tk, den_tk):
    return f"Chuyển {so_tien:,}đ từ {tu_tk} đến {den_tk}"


print(chuyen_tien(500_000, tu_tk="001", den_tk="002"))
# chuyen_tien(500_000, "001", "002") → TypeError: tránh nhầm thứ tự hai tài khoản
Chuyển 500,000đ từ 001 đến 002

3. *args và **kwargs

def tong(*so):                 # gom mọi tham số vị trí thành tuple
    return sum(so)


def tao_the(ten_the, **thuoc_tinh):   # gom tham số theo tên thành dict
    attrs = " ".join(f'{k}="{v}"' for k, v in thuoc_tinh.items())
    return f"<{ten_the} {attrs}>"


print(tong(1, 2, 3), tong())
print(tao_the("input", type="email", name="email"))

ds = [4, 5, 6]
print(tong(*ds))               # * khi gọi: mở list thành các tham số
cau_hinh = {"type": "text", "name": "ho_ten"}
print(tao_the("input", **cau_hinh))   # ** khi gọi: mở dict thành tham số theo tên
6 0
<input type="email" name="email">
15
<input type="text" name="ho_ten">

Tên args, kwargs chỉ là quy ước; dấu *, ** mới quan trọng. Bạn sẽ gặp chúng nhiều khi đọc code thư viện và khi viết decorator ở chặng 5.

4. Phạm vi biến

THUE = 0.08                 # biến toàn cục (hằng số)

def gia_sau_thue(gia):
    tien_thue = gia * THUE  # biến cục bộ, chỉ sống trong hàm
    return gia + tien_thue

print(gia_sau_thue(100_000))
# print(tien_thue) → NameError

dem = 0
def tang_sai():
    dem = dem + 1           # UnboundLocalError: gán làm dem thành biến cục bộ

def tang_dung(gia_tri):
    return gia_tri + 1      # nhận vào, trả ra: không phụ thuộc biến bên ngoài

dem = tang_dung(dem)
print(dem)
108000.0
1

Hàm đọc được biến toàn cục, nhưng hễ có lệnh gán tên đó trong hàm thì Python coi nó là biến cục bộ. Có từ khóa global để sửa biến toàn cục, nhưng gần như luôn có cách tốt hơn: truyền vào qua tham số, trả ra qua return. Hàm như vậy gọi là hàm "thuần": cùng đầu vào luôn cho cùng kết quả, dễ hiểu và dễ test.

5. Bẫy: giá trị mặc định là list

def them_sai(mon, gio=[]):
    gio.append(mon)
    return gio

print(them_sai("táo"))
print(them_sai("cam"))      # bất ngờ: còn "táo" của lần trước!


def them_dung(mon, gio=None):
    if gio is None:
        gio = []
    gio.append(mon)
    return gio

print(them_dung("táo"))
print(them_dung("cam"))
['táo']
['táo', 'cam']
['táo']
['cam']

Giá trị mặc định được tạo một lần lúc định nghĩa hàm, không phải mỗi lần gọi. List mặc định vì vậy bị dùng chung. Luôn dùng None làm mặc định cho list, dict, set.

6. lambda: hàm một dòng không tên

sinh_vien = [("An", 8.5), ("Bình", 7.0), ("Chi", 8.5), ("Dũng", 9.0)]

print(sorted(sinh_vien, key=lambda sv: sv[1], reverse=True))
print(max(sinh_vien, key=lambda sv: sv[1]))
[('Dũng', 9.0), ('An', 8.5), ('Chi', 8.5), ('Bình', 7.0)]
('Dũng', 9.0)

lambda sv: sv[1] tương đương một hàm nhận sv và trả sv[1]. Chỉ dùng lambda cho biểu thức ngắn truyền vào key=; logic dài thì viết def có tên rõ ràng.

Tóm tắt

  • Hàm làm một việc, tên là động từ, có docstring, nhận qua tham số, trả qua return.
  • Tham số mặc định đứng sau; gọi theo tên cho rõ; * bắt buộc gọi theo tên.
  • *args gom tham số vị trí thành tuple, **kwargs gom tham số tên thành dict.
  • Biến trong hàm là cục bộ; tránh global; mặc định cho list dùng None.
  • lambda cho key= ngắn.

Bài tập

Bài 1. Tính hóa đơn

Viết tinh_hoa_don(*gia, giam_gia=0, vat=0.08): cộng các giá, trừ giảm giá theo tỉ lệ (0–1), cộng VAT, làm tròn đến đồng. Giảm giá ngoài 0–1 thì raise ValueError.

Xem đáp án 
def tinh_hoa_don(*gia: int, giam_gia: float = 0, vat: float = 0.08) -> int:
    """Tổng tiền phải trả, làm tròn đến đồng."""
    if not 0 <= giam_gia <= 1:
        raise ValueError("giam_gia phải trong khoảng 0–1")
    tam_tinh = sum(gia) * (1 - giam_gia)
    return round(tam_tinh * (1 + vat))


print(tinh_hoa_don(120_000, 45_000, 35_000))
print(tinh_hoa_don(120_000, 45_000, 35_000, giam_gia=0.1))
print(tinh_hoa_don(99_000, vat=0))
216000
194400
99000

giam_gia và vat đứng sau *gia nên tự động thành tham số bắt buộc gọi theo tên. Bạn sẽ học raise kỹ hơn ở chặng 3.

Bài 2. Sắp xếp nhiều tiêu chí

Sắp xếp sinh viên theo điểm giảm dần; cùng điểm thì theo tên tăng dần.

Xem đáp án 
sinh_vien = [("Chi", 8.5), ("Bình", 7.0), ("An", 8.5), ("Dũng", 9.0), ("Em", 7.0)]
ket_qua = sorted(sinh_vien, key=lambda sv: (-sv[1], sv[0]))
for ten, diem in ket_qua:
    print(f"{ten:<6}{diem}")
Dũng  9.0
An    8.5
Chi   8.5
Bình  7.0
Em    7.0

Key là tuple (-điểm, tên): Python so sánh tuple lần lượt từng phần tử. Đổi dấu điểm để điểm cao xếp trước trong khi tên vẫn tăng dần.
