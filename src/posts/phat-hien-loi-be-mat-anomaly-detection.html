Trong kiểm tra ngoại quan, cái khó nhất thường không phải mô hình mà là dữ liệu lỗi: dây chuyền tốt có thể chỉ sinh vài sản phẩm lỗi mỗi tuần, mỗi loại lỗi lại một kiểu. Anomaly Detection giải quyết đúng vấn đề này: mô hình chỉ học từ ảnh sản phẩm tốt, rồi đánh dấu bất cứ thứ gì "khác thường".

Ý tưởng của PatchCore

PatchCore là một trong những thuật toán anomaly detection hiệu quả và dễ dùng nhất:

  1. Dùng mạng CNN đã huấn luyện sẵn (ví dụ trên ImageNet) để trích đặc trưng cho từng mảnh nhỏ (patch) của ảnh tốt.
  2. Lưu một tập đặc trưng đại diện vào memory bank (có lấy mẫu để gọn).
  3. Với ảnh mới, mỗi patch được so với patch gần nhất trong memory bank. Khoảng cách lớn = bất thường.

Kết quả là một bản đồ bất thường (anomaly map) chỉ ra vị trí lỗi, cùng một điểm số cho cả ảnh. Không cần huấn luyện mạng nhiều epoch, không cần gán nhãn lỗi.

Chuẩn bị dữ liệu

datasets/nap-chai/
  good/        # 100–300 ảnh sản phẩm tốt (huấn luyện)
  defect/      # vài chục ảnh lỗi (chỉ để đánh giá)
  mask/defect/ # (tùy chọn) mặt nạ vùng lỗi để đánh giá cấp pixel

Ảnh phải chụp với cùng điều kiện camera, ánh sáng, vị trí như khi chạy thật. Nếu sản phẩm lệch vị trí nhiều, hãy căn chỉnh (định vị bằng template matching rồi cắt ROI) trước khi đưa vào mô hình.

Huấn luyện với Anomalib

Anomalib là thư viện mã nguồn mở tập hợp nhiều thuật toán anomaly detection (PatchCore, PaDiM, EfficientAD…). Ví dụ dưới đây theo API Anomalib 2.x:

pip install anomalib
from anomalib.data import Folder
from anomalib.engine import Engine
from anomalib.models import Patchcore

datamodule = Folder(
    name="nap_chai",
    root="datasets/nap-chai",
    normal_dir="good",
    abnormal_dir="defect",
    mask_dir="mask/defect",      # bỏ dòng này nếu không có mặt nạ
)

model = Patchcore()              # mặc định backbone wide_resnet50_2
engine = Engine()
engine.fit(model=model, datamodule=datamodule)
engine.test(model=model, datamodule=datamodule)   # in AUROC, F1...

preds = engine.predict(model=model, data_path="anh-moi/")
for batch in preds:                # mỗi phần tử là một batch ảnh
    for path, score, label in zip(batch.image_path, batch.pred_score, batch.pred_label):
        print(path, float(score), "NG" if bool(label) else "OK")

API của Anomalib thay đổi giữa các phiên bản (ví dụ bản 1.x có tham số task mà bản 2.x đã bỏ). Hãy đối chiếu với tài liệu đúng phiên bản bạn cài.

Chọn ngưỡng OK/NG: quyết định của kỹ sư, không phải của mô hình

Mô hình cho điểm số; con người chọn ngưỡng. Hai loại sai cần cân bằng:

  • Lọt lỗi (escape): hàng lỗi bị cho là OK, đến tay khách hàng. Thường rất đắt.
  • Loại nhầm (overkill): hàng tốt bị loại, tốn chi phí và gây phiền cho sản xuất.

Thực tế, nhà máy thường đặt ngưỡng để escape gần bằng 0 và chấp nhận một tỷ lệ overkill nhỏ, những sản phẩm bị loại sẽ được người kiểm tra lại.

Đưa vào sản xuất

  • Xuất mô hình sang OpenVINO hoặc ONNX để chạy trên CPU công nghiệp (Anomalib hỗ trợ engine.export).
  • Đo thời gian xử lý mỗi ảnh so với cycle time dây chuyền.
  • Lưu lại ảnh NG kèm anomaly map để người vận hành xác nhận và để cải thiện mô hình.
  • Theo dõi trôi dữ liệu: đổi lô nguyên liệu, thay đèn, bụi trên ống kính đều làm điểm số thay đổi.
