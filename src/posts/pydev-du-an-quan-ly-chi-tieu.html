Dự án cuối chặng 2: một ứng dụng quản lý chi tiêu chạy trên dòng lệnh. Bạn sẽ dùng list và dict để lưu dữ liệu, chia chương trình thành hàm nhỏ, kiểm tra đầu vào và làm báo cáo theo danh mục, theo tháng. Ở chặng 3, ứng dụng sẽ được nâng cấp để lưu dữ liệu ra file JSON; ở chặng 6, nó trở thành một package có test và cài được như một lệnh.

1. Đặc tả

Viết đặc tả trước khi viết code, như khi nhận việc từ khách hàng:

  • Thêm khoản chi: ngày (dd/mm/yyyy, bỏ trống là hôm nay), số tiền (số nguyên dương, cho phép gõ 45.000), danh mục, ghi chú.
  • Liệt kê các khoản chi có số thứ tự, sắp theo ngày.
  • Báo cáo tổng theo danh mục (kèm tỉ lệ %) và tổng theo tháng.
  • Thoát. Nhập sai không làm chương trình dừng.

2. Thiết kế dữ liệu

Mỗi khoản chi là một dict; cả ứng dụng là một list các dict:

from datetime import date

khoan_chi = {"ngay": date(2026, 10, 3), "so_tien": 45000, "danh_muc": "ăn uống", "ghi_chu": "phở"}
danh_sach = [khoan_chi]
print(danh_sach[0]["so_tien"], danh_sach[0]["ngay"].month)
45000 10

Lưu ngày bằng date chứ không lưu chuỗi: so sánh, sắp xếp, lấy tháng đều dễ. Lưu tiền bằng số nguyên (đồng), không dùng float.

3. Phần xử lý: các hàm không phụ thuộc bàn phím

Quy tắc thiết kế quan trọng nhất của bài: tách phần xử lý khỏi phần nhập xuất. Các hàm dưới đây nhận dữ liệu qua tham số và trả kết quả, không gọi input(), không print(). Nhờ vậy chúng chạy được với dữ liệu mẫu và sau này viết test dễ dàng.

from collections import defaultdict
from datetime import date, datetime


def doc_ngay(chuoi: str, hom_nay: date) -> date:
    """'' → hom_nay; '3/10/2026' → date(2026, 10, 3). Sai định dạng: ValueError."""
    chuoi = chuoi.strip()
    if not chuoi:
        return hom_nay
    return datetime.strptime(chuoi, "%d/%m/%Y").date()


def doc_so_tien(chuoi: str) -> int:
    """'45.000' hoặc '45000' → 45000. Không phải số dương: ValueError."""
    so = int(chuoi.replace(".", "").replace(",", "").strip())
    if so <= 0:
        raise ValueError("Số tiền phải lớn hơn 0")
    return so


def vnd(so: int) -> str:
    return f"{so:,}".replace(",", ".") + "đ"


def tong_theo(danh_sach: list[dict], khoa) -> dict:
    """Cộng số tiền theo nhóm; khoa là hàm lấy tên nhóm từ một khoản chi."""
    tong = defaultdict(int)
    for kc in danh_sach:
        tong[khoa(kc)] += kc["so_tien"]
    return dict(sorted(tong.items(), key=lambda cap: cap[1], reverse=True))


def bao_cao(danh_sach: list[dict]) -> str:
    if not danh_sach:
        return "Chưa có khoản chi nào."
    tong = sum(kc["so_tien"] for kc in danh_sach)
    dong = [f"Tổng chi: {vnd(tong)}", "Theo danh mục:"]
    for dm, tien in tong_theo(danh_sach, lambda kc: kc["danh_muc"]).items():
        dong.append(f"  {dm:<12}{vnd(tien):>12}  {tien / tong:6.1%}")
    dong.append("Theo tháng:")
    theo_thang = tong_theo(danh_sach, lambda kc: kc["ngay"].strftime("%Y-%m"))
    for thang in sorted(theo_thang):
        dong.append(f"  {thang:<12}{vnd(theo_thang[thang]):>12}")
    return "\n".join(dong)


# Chạy thử với dữ liệu mẫu
hom_nay = date(2026, 10, 29)
mau = [

    ("12/10/2026", "350000", "đi lại"), ("28/9/2026", "60.000", "ăn uống"),
    ("", "150.000", "giải trí"),
]

             for n, t, d in mau]
print(bao_cao(danh_sach))

Hàm tong_theo nhận một hàm làm tham số (khoa) để quyết định nhóm theo gì. Một hàm phục vụ cả báo cáo theo danh mục lẫn theo tháng: không cần viết hai vòng lặp gần giống nhau.

4. Phần giao diện dòng lệnh

Thêm vào cuối file (sau các hàm ở mục 3, bỏ phần dữ liệu mẫu) phần nhập xuất. Phần này mỏng, chỉ hỏi, gọi hàm xử lý và in:

# (minh họa) dùng các hàm doc_ngay, doc_so_tien, vnd, bao_cao ở mục 3
def nhap_khoan_chi(hom_nay: date) -> dict:
    while True:
        try:
            ngay = doc_ngay(input("Ngày (dd/mm/yyyy, Enter = hôm nay): "), hom_nay)
            break
        except ValueError:
            print("  Ngày không hợp lệ, ví dụ: 25/10/2026")
    while True:
        try:
            so_tien = doc_so_tien(input("Số tiền: "))
            break
        except ValueError:
            print("  Nhập số nguyên dương, ví dụ: 45.000")
    danh_muc = input("Danh mục: ").strip().lower() or "khác"
    ghi_chu = input("Ghi chú: ").strip()
    return {"ngay": ngay, "so_tien": so_tien, "danh_muc": danh_muc, "ghi_chu": ghi_chu}


def liet_ke(danh_sach: list[dict]) -> None:
    for i, kc in enumerate(sorted(danh_sach, key=lambda k: k["ngay"]), start=1):
        print(f"{i:>3}. {kc['ngay']:%d/%m/%Y}  {vnd(kc['so_tien']):>12}  {kc['danh_muc']:<10} {kc['ghi_chu']}")


def main() -> None:
    danh_sach: list[dict] = []
    while True:
        print("\n[1] Thêm  [2] Liệt kê  [3] Báo cáo  [0] Thoát")
        match input("Chọn: ").strip():
            case "1":
                danh_sach.append(nhap_khoan_chi(date.today()))
                print("  Đã thêm.")
            case "2":
                liet_ke(danh_sach)
            case "3":
                print(bao_cao(danh_sach))
            case "0":
                break
            case _:
                print("  Lựa chọn không hợp lệ.")


if __name__ == "__main__":
    main()

Vài chi tiết đáng học:

  • try/except ValueError bọc lời gọi hàm đọc dữ liệu: nhập sai thì hỏi lại. Bài sau của chặng 3 dạy kỹ cơ chế này; ở đây chỉ cần hiểu "thử, nếu lỗi ValueError thì làm khối except".
  • input(...).strip().lower() or "khác": chuỗi rỗng là "sai", nên or trả giá trị mặc định.
  • f"{kc['ngay']:%d/%m/%Y}": f-string định dạng thẳng đối tượng ngày bằng mã strftime.
  • Hàm main() và khối __main__: import file này từ nơi khác (ví dụ file test) sẽ không tự chạy menu.

Bài tập

Bài 1. Chạy kịch bản kiểm tra

Chạy chương trình, thêm 10 khoản chi thuộc 3 danh mục trong 2 tháng. Tính tay tổng từng danh mục rồi đối chiếu với báo cáo. Thử đủ các dòng của bảng ở mục 5.

Xem gợi ý

Nếu báo cáo lệch với số tính tay, kiểm tra hai chỗ hay sai: danh mục nhập lẫn hoa thường hoặc thừa khoảng trắng (đã được strip().lower() xử lý chưa?), và số tiền có dấu chấm phân cách (đã bỏ dấu chấm trước khi int() chưa?).

Bài 2. Lệnh xóa

Thêm lệnh [4] Xóa: hỏi số thứ tự (theo danh sách đã sắp theo ngày ở lệnh Liệt kê), xóa khoản chi đó; số không hợp lệ thì báo lỗi.

Xem đáp án 
from datetime import date


def xoa_theo_stt(danh_sach: list[dict], stt: int) -> dict:
    """Xóa khoản chi thứ stt (1-based) theo thứ tự ngày; trả về khoản đã xóa."""
    da_sap = sorted(danh_sach, key=lambda k: k["ngay"])
    if not 1 <= stt <= len(da_sap):
        raise ValueError(f"Số thứ tự phải từ 1 đến {len(da_sap)}")
    muc_tieu = da_sap[stt - 1]
    danh_sach.remove(muc_tieu)
    return muc_tieu


ds = [{"ngay": date(2026, 10, 5), "so_tien": 30000, "danh_muc": "a", "ghi_chu": ""},
      {"ngay": date(2026, 10, 1), "so_tien": 50000, "danh_muc": "b", "ghi_chu": ""}]
da_xoa = xoa_theo_stt(ds, 1)
print(da_xoa["so_tien"], len(ds))
try:
    xoa_theo_stt(ds, 5)
except ValueError as loi:
    print("Lỗi:", loi)
50000 1
Lỗi: Số thứ tự phải từ 1 đến 1

Trong main(), thêm nhánh case "4": gọi liet_ke, hỏi số thứ tự, ép int và gọi xoa_theo_stt trong try/except ValueError. Số thứ tự người dùng nhìn thấy bắt đầu từ 1, chỉ số list bắt đầu từ 0: nhớ trừ 1.
