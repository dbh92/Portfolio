OPC UA (Open Platform Communications Unified Architecture) đang trở thành "ngôn ngữ chung" để các thiết bị và phần mềm trong nhà máy trao đổi dữ liệu: PLC, robot, trạm vision, SCADA, MES. Bài này giải thích những khái niệm cơ bản và cách một trạm vision viết bằng Python giao tiếp qua OPC UA.

Vì sao OPC UA?

  • Chuẩn mở, độc lập hãng: PLC của nhiều hãng lớn có sẵn OPC UA server tích hợp.
  • Mô hình dữ liệu có cấu trúc: không chỉ là các thanh ghi số như Modbus, mà là cây đối tượng có tên, kiểu dữ liệu, đơn vị, mô tả.
  • Bảo mật tích hợp: mã hóa, chứng chỉ, xác thực người dùng.
  • Đăng ký nhận thay đổi (subscription): client được thông báo khi giá trị thay đổi, không cần hỏi liên tục.

Các khái niệm chính

  • Server: thiết bị cung cấp dữ liệu (PLC, trạm vision). Client: bên đọc/ghi dữ liệu.
  • Address space: cây các node (đối tượng, biến, phương thức).
  • NodeId: định danh của node, ví dụ ns=2;s=Vision.Result (namespace 2, định danh dạng chuỗi).
  • Endpoint: địa chỉ kết nối dạng opc.tcp://192.168.0.10:4840.

Client Python với asyncua

import asyncio
from asyncua import Client, ua

URL = "opc.tcp://192.168.0.10:4840"

async def main():
    async with Client(url=URL) as client:
        trigger = client.get_node("ns=2;s=Line2.Vision.Trigger")
        result = client.get_node("ns=2;s=Line2.Vision.Result")
        length = client.get_node("ns=2;s=Line2.Vision.LengthMM")

        if await trigger.read_value():
            ok, L = True, 25.012                       # thay bằng kết quả xử lý ảnh
            await result.write_value(ua.Variant(1 if ok else 2, ua.VariantType.Int16))
            await length.write_value(ua.Variant(L, ua.VariantType.Double))

asyncio.run(main())

Kiểu dữ liệu khi ghi phải khớp kiểu của biến trên server (Int16, Double...), nếu không server sẽ từ chối. NodeId thực tế lấy từ cấu hình PLC hoặc duyệt cây bằng công cụ client OPC UA miễn phí.

Đăng ký nhận thay đổi thay vì hỏi liên tục

class Handler:
    async def datachange_notification(self, node, val, data):
        if val:
            print("Có trigger, bắt đầu chụp")

async def watch():
    async with Client(url=URL) as client:
        trigger = client.get_node("ns=2;s=Line2.Vision.Trigger")
        sub = await client.create_subscription(50, Handler())   # chu kỳ 50 ms
        await sub.subscribe_data_change(trigger)
        await asyncio.sleep(3600)

Lời khuyên

  • Tín hiệu trigger yêu cầu tức thời, chính xác mili giây: vẫn dùng I/O số. OPC UA dùng cho dữ liệu kết quả, thông số, trạng thái.
  • Bật bảo mật (chế độ ký và mã hóa) trong môi trường sản xuất thật, không để chế độ không bảo mật.
  • Thử nghiệm với OPC UA server giả lập trước khi kết nối PLC thật.
