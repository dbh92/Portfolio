Trước khi phân tích, ảnh thường phải được "sửa soạn": cắt đúng vùng cần kiểm tra, thu nhỏ để chạy nhanh, xoay về đúng hướng, thêm viền cho đủ kích thước đầu vào mô hình AI. Bài này dạy các thao tác hình học cơ bản đó và những cái bẫy đi kèm: thứ tự (x, y), cắt ra ngoài biên, méo tỉ lệ, góc xoay bị cắt mất.

1. Cắt vùng quan tâm (ROI)

ROI thường được lưu dạng (x, y, w, h): góc trái trên và chiều rộng, cao (đây cũng là định dạng cv2.selectROI và cv2.boundingRect trả về). Cắt bằng slicing NumPy, nhớ hàng (y) trước, cột (x) sau:

def cat_roi(anh, roi):
    """Cắt ROI (x, y, w, h); tự giới hạn trong biên ảnh."""
    x, y, w, h = roi
    cao, rong = anh.shape[:2]
    x1, y1 = max(0, x), max(0, y)
    x2, y2 = min(rong, x + w), min(cao, y + h)
    if x1 >= x2 or y1 >= y2:
        raise ValueError(f"ROI {roi} nằm ngoài ảnh {rong}x{cao}")
    return anh[y1:y2, x1:x2]


vung = cat_roi(anh, (200, 150, 240, 180))
print(vung.shape)                                   # (180, 240, 3)
print(cat_roi(anh, (600, 400, 100, 100)).shape)     # bị cắt bớt ở biên: (80, 40, 3)
(180, 240, 3)
(80, 40, 3)

Vì sao cần hàm riêng? Slicing NumPy không báo lỗi khi cắt ra ngoài biên mà lặng lẽ trả về vùng nhỏ hơn, thậm chí rỗng. Một ROI rỗng đưa vào thuật toán sẽ gây lỗi khó hiểu ở bước sau. Kiểm tra sớm, báo lỗi rõ.

Nhớ: ROI là viewNhư bài NumPy, vung dùng chung bộ nhớ với ảnh gốc. Vẽ lên vung là vẽ lên ảnh gốc. Đôi khi đó chính là điều bạn muốn (tô màu vùng lỗi lên ảnh gốc); nếu không, dùng .copy().

Bẫy: cv2.resize nhận (rộng, cao)Trong khi anh.shape trả về (cao, rộng). Viết cv2.resize(anh, anh.shape[:2]) sẽ cho ảnh bị xoay chiều. Cách an toàn: dùng fx, fy, hoặc ghi rõ (rong, cao).

Resize giữ tỉ lệ và letterbox

Mô hình AI thường cần đầu vào vuông, ví dụ 640×640. Kéo giãn ảnh 640×480 thành 640×640 sẽ làm vật bị méo, mô hình đoán sai. Cách đúng: thu nhỏ giữ tỉ lệ rồi thêm viền (letterbox), cách YOLO dùng:

def letterbox(anh, kich_thuoc=640, mau=(114, 114, 114)):
    """Resize giữ tỉ lệ vào khung vuông, phần thừa tô màu. Trả về ảnh, tỉ lệ, độ dời (dx, dy)."""
    cao, rong = anh.shape[:2]
    ti_le = kich_thuoc / max(cao, rong)
    moi_rong, moi_cao = round(rong * ti_le), round(cao * ti_le)
    thu_nho = cv2.resize(anh, (moi_rong, moi_cao), interpolation=cv2.INTER_AREA)
    dx, dy = (kich_thuoc - moi_rong) // 2, (kich_thuoc - moi_cao) // 2
    khung = cv2.copyMakeBorder(thu_nho, dy, kich_thuoc - moi_cao - dy, dx, kich_thuoc - moi_rong - dx,
                               cv2.BORDER_CONSTANT, value=mau)
    return khung, ti_le, (dx, dy)


lb, ti_le, (dx, dy) = letterbox(anh, 416)
print(lb.shape, round(ti_le, 3), dx, dy)

# Đổi tọa độ trên ảnh letterbox về ảnh gốc (dùng khi mô hình trả về hộp phát hiện)
x_lb, y_lb = 208, 208
print("Về ảnh gốc:", round((x_lb - dx) / ti_le), round((y_lb - dy) / ti_le))
(416, 416, 3) 0.65 0 52
Về ảnh gốc: 320 240

Phải nhớ ti_le và (dx, dy) để đổi kết quả của mô hình về tọa độ ảnh gốc. Quên bước này là lỗi phổ biến nhất khi tự viết phần xử lý sau cho mô hình phát hiện vật.

4. Xoay góc bất kỳ

Để xoay góc tùy ý, tạo ma trận xoay rồi dùng warpAffine:

cao, rong = anh.shape[:2]
tam = (rong / 2, cao / 2)
M = cv2.getRotationMatrix2D(tam, 30, 1.0)     # góc dương = ngược chiều kim đồng hồ
xoay = cv2.warpAffine(anh, M, (rong, cao), borderValue=(0, 0, 0))
print(xoay.shape)

Ảnh giữ nguyên kích thước nên bốn góc bị cắt mất. Muốn giữ trọn ảnh, tính kích thước mới và dịch tâm:

def xoay_giu_tron(anh, goc):
    cao, rong = anh.shape[:2]
    M = cv2.getRotationMatrix2D((rong / 2, cao / 2), goc, 1.0)
    cos, sin = abs(M[0, 0]), abs(M[0, 1])
    moi_rong = int(cao * sin + rong * cos)
    moi_cao = int(cao * cos + rong * sin)
    M[0, 2] += moi_rong / 2 - rong / 2       # dịch để ảnh nằm giữa khung mới
    M[1, 2] += moi_cao / 2 - cao / 2
    return cv2.warpAffine(anh, M, (moi_rong, moi_cao))


print(xoay_giu_tron(anh, 30).shape)
(480, 640, 3)
(735, 794, 3)

Ứng dụng thật của xoay góc bất kỳ là căn thẳng sản phẩm nằm nghiêng trên băng tải trước khi đo hoặc đọc chữ. Bài "Biến đổi hình học" ở chặng 3 sẽ dùng góc lấy từ minAreaRect để làm việc này tự động.

6. Ghép ảnh để so sánh

Đặt ảnh gốc cạnh ảnh kết quả là cách nhanh nhất để kiểm tra thuật toán. Ảnh ghép phải cùng chiều cao (ghép ngang) và cùng số kênh:

def ghep_ngang(*ds_anh, cao=240):
    """Ghép nhiều ảnh (xám hoặc màu) thành một hàng cùng chiều cao."""
    ket = []
    for a in ds_anh:
        if a.ndim == 2:
            a = cv2.cvtColor(a, cv2.COLOR_GRAY2BGR)
        ti_le = cao / a.shape[0]
        ket.append(cv2.resize(a, (round(a.shape[1] * ti_le), cao), interpolation=cv2.INTER_AREA))
    return np.hstack(ket)


xam = cv2.cvtColor(anh, cv2.COLOR_BGR2GRAY)
so_sanh = ghep_ngang(anh, xam, vung)
cv2.imwrite("so_sanh.png", so_sanh)
print(so_sanh.shape)
(240, 960, 3)

Tóm tắt

  • ROI (x, y, w, h) → anh[y:y+h, x:x+w]; kiểm tra biên vì slicing không báo lỗi.
  • cv2.resize nhận (rộng, cao); thu nhỏ dùng INTER_AREA, mặt nạ dùng INTER_NEAREST.
  • Đầu vào mô hình: letterbox giữ tỉ lệ, nhớ tỉ lệ và độ dời để đổi kết quả về ảnh gốc.
  • cv2.flip, cv2.rotate cho góc 90°; getRotationMatrix2D + warpAffine cho góc bất kỳ.
  • Ghép ảnh cùng chiều cao, cùng số kênh để so sánh kết quả.

Bài 1. Lưới ô kiểm tra

import cv2
import numpy as np

anh = np.random.default_rng(0).integers(0, 256, (480, 640, 3), dtype=np.uint8)
so_cot, so_hang = 4, 3
cao_o, rong_o = anh.shape[0] // so_hang, anh.shape[1] // so_cot
for h in range(so_hang):
    for c in range(so_cot):
        o = anh[h * cao_o:(h + 1) * cao_o, c * rong_o:(c + 1) * rong_o]

Bài 2. Đổi hộp phát hiện về ảnh gốc

Mô hình chạy trên ảnh letterbox 640×640 của ảnh gốc 1920×1080 và trả về hộp (x1, y1, x2, y2) = (100, 200, 300, 400). Tính tọa độ hộp trên ảnh gốc.

Xem đáp án 
rong, cao, kt = 1920, 1080, 640
ti_le = kt / max(rong, cao)                   # 1/3
dx = (kt - round(rong * ti_le)) // 2          # 0
dy = (kt - round(cao * ti_le)) // 2           # 140
x1, y1, x2, y2 = 100, 200, 300, 400
goc = [round((x1 - dx) / ti_le), round((y1 - dy) / ti_le), round((x2 - dx) / ti_le), round((y2 - dy) / ti_le)]

Bài 3. Xoay tìm hướng

Viết hàm nhận ảnh và trả về list 4 ảnh xoay 0°, 90°, 180°, 270° (dùng cv2.rotate). Đây là kỹ thuật "test-time augmentation" đơn giản: chạy mô hình trên cả 4 hướng rồi lấy kết quả tin cậy nhất khi sản phẩm có thể nằm theo hướng bất kỳ.

Xem đáp án 
def bon_huong(anh):
    return [anh,
            cv2.rotate(anh, cv2.ROTATE_90_CLOCKWISE),
            cv2.rotate(anh, cv2.ROTATE_180),
            cv2.rotate(anh, cv2.ROTATE_90_COUNTERCLOCKWISE)]


print([a.shape for a in bon_huong(np.zeros((100, 200), np.uint8))])
[(100, 200), (200, 100), (100, 200), (200, 100)]
