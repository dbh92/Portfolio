Thói quen tốt

  • Commit nhỏ, thường xuyên, mỗi commit một mục đích.
  • git pull trước khi bắt đầu làm việc, git status trước khi commit.
  • Không dùng git push --force lên nhánh dùng chung.
  • Không commit mật khẩu, khóa API, dữ liệu khách hàng.
