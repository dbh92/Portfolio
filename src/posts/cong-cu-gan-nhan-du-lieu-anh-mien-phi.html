Gán nhãn (annotation) là khâu tốn thời gian nhất của một dự án AI Vision, thường chiếm phần lớn công sức so với huấn luyện mô hình. Chọn đúng công cụ và quy trình giúp tiết kiệm hàng tuần làm việc. Bài này so sánh các công cụ gán nhãn ảnh miễn phí phổ biến.

Các công cụ nên biết

CVAT

  • Mã nguồn mở, chạy trên trình duyệt; tự cài bằng Docker hoặc dùng bản cloud.
  • Hỗ trợ khung bao, đa giác, keypoint, phân đoạn, gán nhãn video theo khung hình với nội suy.
  • Quản lý dự án, phân công nhiều người gán nhãn, kiểm duyệt.
  • Xuất nhiều định dạng: YOLO, COCO, Pascal VOC…
  • Hợp với: nhóm làm dự án nghiêm túc, cần làm việc nhiều người.

Label Studio

  • Mã nguồn mở, cài nhanh bằng pip install label-studio rồi chạy label-studio start.
  • Không chỉ ảnh mà cả văn bản, âm thanh, chuỗi thời gian; giao diện gán nhãn tùy biến bằng cấu hình.
  • Kết nối được với mô hình để gán nhãn trước (pre-annotation).
  • Hợp với: dự án nhiều loại dữ liệu, cần tùy biến giao diện.

X-AnyLabeling

  • Ứng dụng desktop mã nguồn mở, tích hợp sẵn nhiều mô hình AI hỗ trợ gán nhãn tự động (YOLO, SAM…).
  • Bấm một điểm, mô hình phân đoạn tự vẽ đa giác quanh vật, nhanh hơn nhiều so với vẽ tay.
  • Hợp với: cá nhân, dự án phân đoạn cần tốc độ.

LabelMe

  • Công cụ desktop gọn nhẹ, lưu nhãn dạng JSON, chủ yếu cho đa giác và phân đoạn.
  • Hợp với: dự án nhỏ, người mới bắt đầu.

Roboflow Annotate

  • Dịch vụ trên web có gói miễn phí, tích hợp gán nhãn, tăng cường dữ liệu, xuất sẵn định dạng cho YOLO.
  • Lưu ý điều khoản dữ liệu ở gói miễn phí (dữ liệu có thể ở chế độ công khai). Không dùng cho dữ liệu mật của khách hàng nếu chưa kiểm tra kỹ.

Quy trình gán nhãn hiệu quả

  1. Viết hướng dẫn gán nhãn trước khi bắt đầu: định nghĩa từng lớp, ảnh ví dụ đúng/sai, quy tắc với vật bị che khuất hoặc bị cắt ở mép ảnh.
  2. Gán nhãn thủ công 100–200 ảnh đầu tiên thật cẩn thận.
  3. Huấn luyện mô hình sơ bộ, dùng nó gán nhãn trước phần còn lại; người gán nhãn chỉ sửa lỗi.
  4. Kiểm tra chéo một phần dữ liệu: hai người gán cùng ảnh, so sánh độ thống nhất.
  5. Ưu tiên gán nhãn các ảnh mô hình đang làm sai thay vì thêm ảnh dễ.

Định dạng nhãn hay gặp

  • YOLO: mỗi ảnh một file .txt, mỗi dòng class cx cy w h chuẩn hóa 0–1.
  • COCO: một file JSON chung cho cả tập, hỗ trợ khung bao, phân đoạn, keypoint.
  • Pascal VOC: mỗi ảnh một file XML, tọa độ tính bằng pixel.

Có nhãn rồi, thử huấn luyện mô hình đầu tiên với bài Object Detection với YOLO26.
