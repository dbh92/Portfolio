Khi bài toán quá phức tạp để viết luật bằng tay (vật đa dạng hình dạng, nền lộn xộn, ánh sáng thay đổi), ta chuyển sang Object Detection bằng Deep Learning. Họ mô hình phổ biến nhất cho việc này là YOLO, và phiên bản Ultralytics mới nhất hiện tại là YOLO26 (ra mắt tháng 1/2026).

YOLO26 có gì mới?

  • Không cần NMS (end-to-end): mô hình trả thẳng các khung cuối cùng, bỏ bước hậu xử lý Non-Maximum Suppression, giúp triển khai trên thiết bị biên đơn giản và nhanh hơn.
  • Bỏ DFL (Distribution Focal Loss) ở đầu dự đoán khung, xuất mô hình sang ONNX/TensorRT gọn hơn.
  • Công thức huấn luyện mới: bộ tối ưu MuSGD, ProgLoss và STAL (cải thiện vật nhỏ).
  • Theo tài liệu Ultralytics, YOLO26n chạy CPU (ONNX) nhanh hơn tới khoảng 43% so với YOLO11n; YOLO26n đạt 40,9 mAP50-95 trên COCO.

Một lưu ý pháp lý: thư viện Ultralytics phát hành theo giấy phép AGPL-3.0. Dùng trong sản phẩm thương mại đóng mã nguồn cần mua giấy phép Enterprise.

Cài đặt và chạy thử

pip install ultralytics
from ultralytics import YOLO

model = YOLO("yolo26n.pt")               # tự tải trọng số đã huấn luyện trên COCO
results = model("duong-pho.jpg")         # dự đoán
for r in results:
    for box in r.boxes:
        cls = model.names[int(box.cls)]
        conf = float(box.conf)
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        print(f"{cls}: {conf:.2f} tại ({x1:.0f},{y1:.0f})-({x2:.0f},{y2:.0f})")
results[0].save("ket-qua.jpg")

Các cỡ mô hình: n (nano), s, m, l, x. Bắt đầu bằng n hoặc s, chỉ tăng cỡ khi độ chính xác chưa đủ.

Huấn luyện trên dữ liệu của bạn

1. Chuẩn bị dữ liệu theo định dạng YOLO

dataset/
  images/train/  images/val/
  labels/train/  labels/val/      # mỗi ảnh một file .txt cùng tên

Mỗi dòng trong file nhãn là một vật: class cx cy w h, tọa độ chuẩn hóa về 0–1 theo kích thước ảnh. Ví dụ 0 0.512 0.430 0.120 0.085. Dùng công cụ gán nhãn như CVAT hoặc Label Studio để xuất đúng định dạng.

2. File cấu hình data.yaml

path: dataset
train: images/train
val: images/val
names:
  0: vit
  1: oc
  2: long_den

3. Huấn luyện

from ultralytics import YOLO

model = YOLO("yolo26n.pt")               # transfer learning từ trọng số COCO
model.train(data="data.yaml", epochs=100, imgsz=640, batch=16)

metrics = model.val()
print(metrics.box.map50, metrics.box.map)   # mAP50 và mAP50-95

Kết quả (biểu đồ loss, ma trận nhầm lẫn, trọng số tốt nhất best.pt) nằm trong thư mục runs/detect/train*/.

Mẹo để mô hình tốt hơn

  • Dữ liệu quan trọng hơn mô hình. 300 ảnh gán nhãn cẩn thận, đa dạng góc chụp và ánh sáng tốt hơn 3.000 ảnh na ná nhau.
  • Tập validation phải giống điều kiện thực tế ở nhà máy, không lấy ngẫu nhiên từ cùng một đoạn video với tập train.
  • Vật nhỏ: tăng imgsz (ví dụ 1024) hoặc cắt ảnh thành ô (tiling).
  • Xem kỹ các ảnh mô hình sai trong tập val, bổ sung dữ liệu đúng loại đó thay vì tăng epoch.

Xuất mô hình để triển khai

model = YOLO("runs/detect/train/weights/best.pt")
model.export(format="onnx")              # hoặc "engine" (TensorRT), "openvino"

File ONNX chạy được bằng ONNX Runtime trong C#, C++ hoặc Python trên máy tính công nghiệp. Đây chính là chặng Deployment trong lộ trình Vision Engineer.

Bài tập

  1. Chạy YOLO26n trên webcam và in số người trong khung hình.
  2. Chụp và gán nhãn 100 ảnh 2 loại vật dụng trên bàn, huấn luyện 50 epoch, ghi lại mAP50.
  3. Xuất ONNX và so sánh tốc độ CPU giữa .pt và .onnx.
