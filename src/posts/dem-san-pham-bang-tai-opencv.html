Đếm sản phẩm đi qua băng tải là dự án Machine Vision "nhập môn" kinh điển: bài toán rõ ràng, chạy được chỉ với webcam và OpenCV, nhưng đủ các vấn đề thật như ánh sáng, vật dính nhau, đếm trùng. Dự án này dùng hoàn toàn thuật toán cổ điển, không cần GPU.

Yêu cầu bài toán

  • Camera đặt phía trên băng tải, nhìn thẳng xuống.
  • Sản phẩm (ví dụ hộp, chai, linh kiện) đi từ trái sang phải.
  • Đếm mỗi sản phẩm đúng một lần khi nó đi qua một vạch ảo.

Thiết kế phần cứng trước, phần mềm sau

  • Nền tương phản: băng tải đen với sản phẩm sáng (hoặc ngược lại) giúp phân ngưỡng ổn định.
  • Đèn khuếch tán cố định, che ánh sáng ngoài: ánh nắng qua cửa sổ là "kẻ thù" số 1.
  • Thời gian phơi sáng ngắn để ảnh không nhòe khi băng tải chạy nhanh.

Thuật toán

  1. Cắt ROI là dải băng tải.
  2. Phân ngưỡng + hình thái học để tách sản phẩm.
  3. Tìm contour, lấy tâm từng sản phẩm.
  4. Theo dõi tâm qua các khung hình bằng "tracker" đơn giản (ghép tâm gần nhất).
  5. Khi một tâm đi từ trái sang phải vạch đếm thì tăng bộ đếm.

Mã nguồn

import cv2
import numpy as np

VIDEO = "bang-tai.mp4"         # hoặc 0 để dùng webcam
ROI = (0, 120, 640, 240)       # x, y, w, h của dải băng tải
LINE_X = 320                   # vạch đếm (tọa độ trong ROI)
MIN_AREA = 800                 # diện tích tối thiểu của một sản phẩm
MAX_DIST = 60                  # khoảng cách tối đa để ghép cùng một vật

cap = cv2.VideoCapture(VIDEO)
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (7, 7))
tracks = {}                    # id -> (cx, cy)
next_id, count = 0, 0

while True:
    ok, frame = cap.read()
    if not ok:
        break
    x, y, w, h = ROI
    roi = frame[y:y + h, x:x + w]
    gray = cv2.GaussianBlur(cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY), (5, 5), 0)
    _, th = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    th = cv2.morphologyEx(th, cv2.MORPH_OPEN, kernel)

    contours, _ = cv2.findContours(th, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    centers = []
    for c in contours:
        if cv2.contourArea(c) < MIN_AREA:
            continue
        M = cv2.moments(c)
        centers.append((int(M["m10"] / M["m00"]), int(M["m01"] / M["m00"])))

    # Ghép tâm mới với track cũ gần nhất
    new_tracks = {}
    for cx, cy in centers:
        best, best_d = None, MAX_DIST
        for tid, (px, py) in tracks.items():
            d = np.hypot(cx - px, cy - py)
            if d < best_d and tid not in new_tracks:
                best, best_d = tid, d
        if best is None:
            best, next_id = next_id, next_id + 1
        else:
            px, _ = tracks[best]
            if px < LINE_X <= cx:        # vừa vượt vạch từ trái sang phải
                count += 1
        new_tracks[best] = (cx, cy)
        cv2.circle(roi, (cx, cy), 5, (0, 0, 255), -1)
    tracks = new_tracks

    cv2.line(roi, (LINE_X, 0), (LINE_X, h), (0, 255, 255), 2)
    cv2.putText(frame, f"Count: {count}", (10, 40), cv2.FONT_HERSHEY_SIMPLEX, 1.2, (0, 255, 0), 3)
    cv2.imshow("Dem san pham", frame)
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

cap.release()
cv2.destroyAllWindows()
print("Tổng:", count)

Những lỗi thường gặp và cách sửa

Hiện tượngNguyên nhânCách sửa
Đếm 2 lần một vậtContour bị tách đôi do phản xạTăng kernel morphology, dùng đèn khuếch tán
Hai vật đếm thành mộtVật sát nhau, dính contourChia theo diện tích chuẩn, hoặc tách hàng bằng cơ khí
Mất đếm khi băng tải nhanhVật di chuyển quá xa giữa 2 khungTăng FPS, tăng MAX_DIST, giảm phơi sáng
Đếm sai khi trời nắngÁnh sáng ngoài làm ngưỡng thay đổiChe chắn, dùng Otsu hoặc ngưỡng thích nghi

Nâng cấp lên mức "nhà máy"

  • Dùng cảm biến quang (photo sensor) để trigger camera chụp đúng lúc sản phẩm vào vị trí, thay vì xử lý video liên tục.
  • Gửi số đếm và tín hiệu OK/NG sang PLC qua I/O hoặc Modbus TCP (xem bài giao tiếp vision với PLC).
  • Lưu log theo ca, ảnh các trường hợp bất thường để phân tích.

Khi sản phẩm đa dạng hình dạng hoặc nền phức tạp, thay bước phân ngưỡng bằng mô hình YOLO và tracker có sẵn, xem dự án đếm người qua cửa bằng YOLO + tracking.
