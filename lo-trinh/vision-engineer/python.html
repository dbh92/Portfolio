Chặng 1: Python

Học xong chặng này, bạn có thể: Viết script xử lý dữ liệu và thao tác trực tiếp trên mảng ảnh bằng NumPy.

  • 11 bài học
  • ~12 giờ học
  • ~4 tuần
  • 0/11 bài đã học
Bắt đầu bài 1 Xem cả lộ trình

Trước khi bắt đầu

Không cần biết lập trình. Chỉ cần máy tính Windows, macOS hoặc Linux có kết nối mạng.

Chặng này gồm

  • Cú pháp, kiểu dữ liệu, hàm, module và xử lý lỗi
  • NumPy: mảng nhiều chiều, slicing, phép toán vector hóa
  • Môi trường ảo, pip, đọc/ghi file và cấu trúc một dự án nhỏ

Bài học theo thứ tự

Học lần lượt từ trên xuống. Làm hết bài tập trong mỗi bài, đánh dấu đã học để theo dõi tiến độ.

  1. 1

    Cài Python, VS Code và chạy chương trình đầu tiên

    Cài đúng Python 3 và VS Code · Chạy file .py bằng terminal và nút Run · Đọc hiểu thông báo lỗi đầu tiên

    Bài học~40 phút
  2. 2

    Biến, kiểu dữ liệu và toán tử

    Dùng int, float, str, bool đúng chỗ · Ép kiểu và định dạng chuỗi bằng f-string · Nhận biết lỗi chia số nguyên, làm tròn số thực

    Bài học~60 phút
  3. 3

    Rẽ nhánh và vòng lặp

    Viết if/elif/else cho tiêu chí OK/NG · Dùng for, while, range, break, continue · Tránh vòng lặp vô hạn

    Bài học~60 phút
  4. 4

    List, tuple, dict và set

    Chọn cấu trúc dữ liệu phù hợp · Duyệt, lọc, sắp xếp dữ liệu · Dùng list comprehension và dict để thống kê

    Bài học~75 phút
  5. 5

    Hàm và module

    Viết hàm có tham số mặc định và giá trị trả về · Tách code thành module và import · Viết docstring, type hint cơ bản

    Bài học~75 phút
  6. 6

    Đọc ghi file, pathlib và xử lý lỗi

    Đọc ghi file văn bản với with · Làm việc với đường dẫn bằng pathlib · Bắt lỗi bằng try/except đúng cách

    Bài học~60 phút
  7. 7

    Môi trường ảo, pip và thư viện cho AI Vision

    Tạo môi trường ảo cho từng dự án · Cài thư viện bằng pip và lưu requirements · Kiểm tra PyTorch nhận GPU

    Bài học~45 phút
  8. 8

    Xử lý thư mục ảnh, CSV và log

    Duyệt hàng nghìn ảnh bằng pathlib · Ghi kết quả ra CSV mở được bằng Excel · Ghi log thay cho print

    Thực hành~60 phút
  9. 9

    NumPy cơ bản: mảng, slicing, vector hóa

    Tạo mảng, hiểu shape và dtype · Cắt mảng bằng slicing và mặt nạ boolean · Thay vòng lặp bằng phép toán vector hóa

    Bài học~75 phút
  10. 10

    Ảnh là mảng số: NumPy cho xử lý ảnh

    Hiểu ảnh xám, ảnh màu, thứ tự BGR · Cắt ROI và tạo mặt nạ · Tránh bẫy tràn số uint8

    Bài học~60 phút
  11. 11

    Dự án chặng 1: báo cáo chất lượng thư mục ảnh

    Kết hợp pathlib, NumPy, CSV, logging trong một chương trình · Phát hiện ảnh hỏng, quá tối, quá sáng · Viết code chia hàm rõ ràng, chạy lại được

    Dự án~120 phút
