Giai đoạn 1Nền tảng ngôn ngữ

  1. 1

    Chặng 1: Bắt đầu: cú pháp và tư duy lập trình

    Bạn đang ở đây ~2 tuần

    Bạn sẽ học

    • Cài Python, VS Code, chạy file .py và đọc thông báo lỗi
    • Biến, kiểu dữ liệu, toán tử, nhập xuất và chuỗi f-string
    • Rẽ nhánh if/match, vòng lặp for/while và cách chia bài toán thành bước nhỏ

    Học xong bạn có thể

    Viết được chương trình nhỏ có nhập liệu, tính toán, rẽ nhánh và vòng lặp, tự sửa lỗi cú pháp thường gặp.

    5 bài học · ~5 giờ 0/5 bài
    1. Cài Python, VS Code và chạy chương trình đầu tiênBài học
    2. Biến, kiểu dữ liệu, toán tử và nhập liệuBài học
    3. Chuỗi: cắt, tìm, thay và định dạng f-stringBài học
    4. Rẽ nhánh và vòng lặp: if, match, for, whileBài học
    5. Thực hành: trò chơi đoán số và tính tiền điện bậc thangThực hành
    Vào học chặng 1
  2. 2

    Chặng 2: Cấu trúc dữ liệu và hàm

    Bạn đang ở đây ~2 tuần

    Bạn sẽ học

    • List, tuple, dict, set: chọn đúng cấu trúc cho từng việc
    • Hàm: tham số, giá trị trả về, *args, **kwargs, phạm vi biến, lambda
    • Module, package và thư viện chuẩn: datetime, random, math, collections

    Học xong bạn có thể

    Tổ chức chương trình thành hàm và module, lưu trữ và thống kê dữ liệu bằng list, dict, set.

    5 bài học · ~6 giờ 0/5 bài
    1. List và tupleBài học
    2. Dict và set: tra cứu và đếm nhanhBài học
    3. Hàm: tham số, giá trị trả về, phạm vi và lambdaBài học
    4. Module, package và thư viện chuẩnBài học
    5. Dự án chặng 2: ứng dụng quản lý chi tiêu dòng lệnhDự án
    Vào học chặng 2
  3. 3

    Chặng 3: File, dữ liệu và xử lý lỗi

    Bạn đang ở đây ~2 tuần

    Bạn sẽ học

    • Đọc ghi file văn bản, encoding UTF-8 và đường dẫn bằng pathlib
    • Lưu trữ dữ liệu bằng JSON, CSV
    • Xử lý ngoại lệ đúng cách và ghi log bằng logging

    Học xong bạn có thể

    Viết script làm việc với file và thư mục thật, lưu được dữ liệu, không chết khi gặp dữ liệu lỗi và có log để truy vết.

    5 bài học · ~5 giờ 0/5 bài
    1. Đọc ghi file và đường dẫn với pathlibBài học
    2. Lưu dữ liệu bằng JSON và CSVBài học
    3. Xử lý ngoại lệ: try, except, raiseBài học
    4. Ghi log bằng logging thay cho printBài học
    5. Thực hành: script tự dọn dẹp thư mục DownloadsThực hành
    Vào học chặng 3

Giai đoạn 2Viết Python chuyên nghiệp

  1. 4

    Chặng 4: Lập trình hướng đối tượng

    Bạn đang ở đây ~3 tuần

    Bạn sẽ học

    • Class, đối tượng, thuộc tính, phương thức và property
    • Phương thức đặc biệt để đối tượng dùng được với print, ==, sorted, len
    • Kế thừa, composition, lớp trừu tượng, dataclass và Enum

    Học xong bạn có thể

    Mô hình hóa bài toán thành các lớp rõ ràng, viết được đối tượng dùng tự nhiên như kiểu có sẵn của Python.

    5 bài học · ~6 giờ 0/5 bài
    1. Class và đối tượngBài học
    2. Phương thức đặc biệt và propertyBài học
    3. Kế thừa, composition và lớp trừu tượngBài học
    4. dataclass, Enum và NamedTupleBài học
    5. Dự án chặng 4: quản lý thư viện sách bằng OOPDự án
    Vào học chặng 4
  2. 5

    Chặng 5: Python nâng cao: code Pythonic

    Bạn đang ở đây ~3 tuần

    Bạn sẽ học

    • Comprehension, unpacking, enumerate, zip và các hàm dựng sẵn
    • Iterator, generator, itertools để xử lý dữ liệu lớn tốn ít bộ nhớ
    • Closure, decorator, context manager và type hint nâng cao

    Học xong bạn có thể

    Đọc hiểu code Python chuyên nghiệp và viết code ngắn gọn, rõ ràng, có kiểm tra kiểu tĩnh.

    5 bài học · ~5 giờ 0/5 bài
    1. Comprehension, unpacking và hàm dựng sẵnBài học
    2. Iterator, generator và itertoolsBài học
    3. Closure và decoratorBài học
    4. Context manager và câu lệnh withBài học
    5. Type hint nâng cao và kiểm tra kiểu bằng mypyBài học

    Bạn sẽ học

    • Môi trường ảo, pip, uv và pyproject.toml

    Dựng dự án Python có môi trường riêng, quản lý bằng Git, tự động format, lint, có test và chạy được như một lệnh.

    4. Kiểm thử tự động với pytestBài học
    5. Debug: breakpoint, VS Code và pdbBài học
    6. Cấu trúc dự án chuẩn và đóng gói thành lệnhBài học

    Chặng 7: Tự động hóa công việc

    Bạn đang ở đây ~3 tuần

    Bạn sẽ học

    Tự động hóa được một công việc lặp lại hằng ngày: lấy dữ liệu, xử lý, xuất báo cáo Excel và chạy theo lịch.

    1. Công cụ dòng lệnh với argparse và TyperBài học

    3. Tự động hóa Excel với openpyxlBài học
    4. Biểu thức chính quy với module reBài học
    5. subprocess và chạy script theo lịchBài học

  2. 8

    Chặng 8: Cơ sở dữ liệu và xử lý dữ liệu

    Bạn đang ở đây ~3 tuần

    Bạn sẽ học

    • SQL cơ bản với SQLite: tạo bảng, truy vấn, JOIN, GROUP BY
    • SQLAlchemy 2.0 ORM: model, session, quan hệ

    Học xong bạn có thể

    Lưu trữ dữ liệu ứng dụng trong cơ sở dữ liệu quan hệ và phân tích bảng dữ liệu hàng chục nghìn dòng.

    4 bài học · ~5 giờ 0/4 bài
    1. SQL cơ bản với sqlite3Bài học
    2. SQLAlchemy 2.0 ORMBài học
    3. pandas cơ bản cho lập trình viênBài học
    4. Thực hành: phân tích dữ liệu bán hàng từ SQLiteThực hành
    Vào học chặng 8

    Chặng 9: Web API với FastAPI

    Bạn đang ở đây ~4 tuần

    6 bài học · ~8 giờ 0/6 bài

    2. FastAPI đầu tiên: endpoint và PydanticBài học
    3. FastAPI với cơ sở dữ liệu SQLAlchemyBài học
    4. Xác thực người dùng: băm mật khẩu và JWTBài học
    5. Kiểm thử API FastAPI với pytestBài học
    6. Dự án chặng 9: API quản lý công việc nhómDự án

Python Developer

Viết, kiểm thử và triển khai phần mềm Python chất lượng: công cụ tự động hóa, xử lý dữ liệu và backend Web API, làm việc được trong một nhóm phát triển chuyên nghiệp.

Bạn có thể làm

  • Viết code Python rõ ràng theo PEP 8, có type hint và test tự động

  • Python Developer
  • Backend Developer (Python)
  • Automation Engineer
  • Junior Data Engineer
